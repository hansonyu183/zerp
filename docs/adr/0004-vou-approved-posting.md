# VOU 在审批时入账，批准是唯一终态

所有会产生业务台账流水的 VOU 单据统一在 `APPROVED` 时写入对应台账，并在 `unapprove` 时撤销对应台账流水；该规则覆盖库存、资金、往来、空桶等 LED 台账，不为不同账簿保留第二套入账时点。不会产生台账流水的单据同样以 `APPROVED` 作为唯一终态。

VOU 生命周期固定为 `DRAFT ⇄ CHECKED ⇄ APPROVED`。`APPROVED` 表示审批与必要入账已在同一事务中完成；反批准直接从 `APPROVED` 回到 `CHECKED` 并撤销对应台账事实。系统不维护额外的完成状态，也不提供完成、重开或短结动作。

订单履约量仍由已批准的下游单据计算，用于限制可出库、可入库、可退数量和结算资金保留量；这些数量事实不改变订单或流程实例的生命周期。LED 期间结账阻止会改变台账的 `approve/unapprove`，但不阻止在开放期间为历史订单创建草稿。

本次语义切换不保留旧状态兼容层或双写路径；迁移在发现旧生命周期数据时直接失败，要求先清理环境。切换完成后系统只保留 `APPROVED` 入账语义。
