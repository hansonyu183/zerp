# RPT permissions are APP-managed and cross-book

RPT 首次验证保存一张报表时，以报表稳定编码在 APP 中原子注册独立的查询和导出权限，后续角色授权及请求校验继续由 APP 统一管理，不建立第二套 RPT 角色权限体系。报表当前定义不可执行时停用权限但保留角色关联，修正并验证保存后恢复原授权；稳定编码在创建后不可修改，报表不提供删除身份的入口。报表访问权有意不继承 ACC 的用户账簿分配范围：获得某张报表权限即可以读取该报表定义返回的全部数据，包括跨账簿数据；数据范围由受信任的报表 SQL 维护人员负责，因此授予报表权限必须被视为独立的数据访问决策。
