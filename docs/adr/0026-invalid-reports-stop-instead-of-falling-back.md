# Invalid reports stop instead of falling back

RPT 将报表版本的审批状态与当前有效性分开保存。批准前必须解析、准备、解释并限量试跑查询，同时验证参数和结果列契约；已批准版本后来遇到确定性的 SQL 结构错误时标记为无效并停用其查询和导出权限，但保留审批历史和角色关联。系统不会继续重复执行已知无效的 SQL，也不会自动回退到历史口径；恢复必须通过批准一个重新验证过的新版本完成。数据库基线变化必须在重建内测库前验证全部当前有效报表，不兼容时阻断发布；修复方式是同次提供兼容的新版本或事先明确停用报表，不保留旧结构兼容视图。
