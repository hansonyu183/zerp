# PAY 暂缓，未来从新输入模型重建

## 决定

PAY 当前不进入实现。ADR-0002 的工资计算单、发放单、台账和与员工借款的联动规格不再是可恢复的设计；已关闭且标记为不计划实施的 Issue #114 不构成实现授权。

未来若重新启动 PAY，必须从新的工资输入模型定义最小端到端范围，并先批准新的 PAY ADR、领域规则和 OpenAPI。新设计不得把旧规格接回其他往来、Party 关系或既有付款单。

## 后果

当前仓库不维护 `docs/domains/pay.md`、PAY HTTP 契约、页面或迁移。任何 PAY 实现请求先形成新的决策和明确范围，不能把 ADR-0002 当作待实现规格。
