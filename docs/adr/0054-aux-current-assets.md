# 仓库、资金账户和车辆归 AUX 直接维护

按 [#395](https://github.com/hansonyu183/zerp/issues/395)，三类对象沿用 AUX current 的稳定身份、revision、独立启停与审计，不再拥有 DCL Submission 或业务版本。领域约束见 [AUX](../domains/aux.md#310-仓库资金账户与车辆)。

本决定部分替换 ADR-0047、ADR-0049 中三类对象由 DCL 持有身份和版本的条款。其他尚未迁移档案的生命周期继续有效。仓库负责人、账户所属主体及车辆内部承运方采用 AUX；外部承运方仍通过 Other Unit 当前真实读取接口采用精确版本。一次性转换保留稳定身份、编码、历史采用快照、精确来源与审计，未决冲突返回 blocker；旧数据只作历史证据，不参与新采用或回退读取。

直接维护减少审批编排，但不削弱库存、进行中单据、账号唯一性、承运及引用约束。保存与引用、revision 和审计同事务，冲突全部回滚；禁止自动迁移引用或停用关联对象。临时表单沿用 ADR-0053。

同时部分替代 ADR-0046 对本文 AUX 资源的 DCL 写入要求；其 AUX 直接维护、公共审批职责、事务与授权原则保留。
