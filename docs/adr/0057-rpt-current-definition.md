# RPT 使用单一当前定义和只读报表页

依据 #392 与 #400，RPT 自己持有 stable ID/code、单一当前内容、revision 与技术有效性。定义维护独立授权，验证成功后直接保存；不使用 DCL、BOB、Approval、候选或业务版本。普通用户的真实资源页只提供类型化参数查询与导出，不套用资料 ListPage，也不建立通用报表设计平台。

本决定替换 ADR-0046 的 RPT 版本写入约束、ADR-0047 的 RPT 身份及计数器归属、ADR-0050 的 RPT 批准时校验条款。其余领域的所有权与数据库持久化边界继续有效。ADR-0025 的 APP 精确授权和跨账簿规则、ADR-0026 的失效停止与无历史 fallback 原则保留：校验改为当前定义保存及执行前校验，修正验证后恢复同一身份。

转换保留旧定义与 Approval 只读历史证据和运行审计，不重解释交易快照。最高已批准内容成为当前配置；只有开放 V1 时保留为待修正验证的无效配置，其他未决候选阻止转换。旧 query/get 只转换为维护读取权限，save 不从提交或审批权限自动推导。原报表 query/export 授权及角色关联保持。
