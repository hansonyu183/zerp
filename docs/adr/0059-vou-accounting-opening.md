# 会计期初由 VOU 拥有并调用 ACC 同事务事实能力

VOU 拥有每账簿唯一的 Approval-only 会计期初稳定主体、不可变提交、列表、详情与审批。稳定身份继续使用 bookId，原 Approval Entry、快照、精确引用和审计身份保持；无业务版本、启停、持久化草稿或第二个 ACC 审批入口。共享 VOU 类型包含 opening；普通业务凭证的映射与事件类型仍单独限定，期初不重复生成普通凭证。

VOU 使用公共 ApprovalPersistence 并拥有外层事务；ACC 在此事务内执行逐币种平衡、末级科目与维度、库存数量、资产、票据和空桶校验，生成或撤销 OPENING 账务事实。后续记账和期间锁定与期初审批锁协调；反批准有后续凭证、锁定期间或全局对象后续采用时返回 blocker，审批、审计和效果整体回滚。

新建账簿不会隐式提交或批准零期初。页面临时输入关闭、刷新或账号变化即销毁，确定失败保留，未知提交结果禁止重放；已有提交只能复制到临时表单，并显式删除开放提交后另行提交。权限和账簿范围交集决定动作，批准人必须不同于提交人。

一次性迁移保留历史，转换旧 ACC 期初权限：旧 query 原为单账簿详情，转换为 VOU query 与 get；其他同名动作一对一转换。新 audit-history 读取权限独立分配。历史快照表名继续作为持久化身份，不提供旧路由或读取 fallback。

本决定部分替代 ADR-0051 中 ACC 持有期初提交审批以及期初本地持久化草稿的条款，及 ADR-0052 的会计期初尚未迁移描述；其他领域、职责分离、契约与同事务规则保持。

对应 [#404](https://github.com/hansonyu183/zerp/issues/404) 与 [#392](https://github.com/hansonyu183/zerp/issues/392)。
