# 动态页面拥有交互生命周期

逐页编辑器重复管理请求、权限和刷新，使相同操作产生不同语义。按 #408–#413，已登记 APP/AUX、五类 BOB 版本档案、WFL 流程定义、VOU、ACC 映射、RPT 报表及 WFL 实例资源只提供一个强类型 definition，包含资源身份、有限字段及无状态类型化数据适配；六类动态页面在实例内拥有查询、编辑、动作互斥、反馈和刷新。基础列、关键词、分页和弹窗采用运行时默认值。Registry 直接绑定定义，不保留仅转发参数的页面包装。

本决定部分替代 [ADR-0052](0052-session-dynamic-navigation-and-page-migration.md) 中逐页 VM、专有字段编辑器及页面交互回调的条款；保留其 Session、精确授权、强字段契约、查询快照、异步隔离和本地 Draft 生命周期。配置页只接受 ACC 映射定义，报表页接受报表编码定义，流程运行页接受 WFL 实例定义；类型化适配保持现有协议，有限资源不增加可配置回调。

字段仅访问顶层键，复用有限值语义并增加实际消费者需要的多行文本、密码、多选及有限条件显示。筛选和编辑分别提交；定义不接受任意路径、组件、模板、脚本或表达式。引用绑定有限真实授权来源，各字段请求独立隔离，完整保留既有关联；候选采用和委派上限仍由领域服务校验。

运行时只通过类型化 API 适配查询与写入。取消不刷新，确认写入成功刷新一次，刷新失败不重放；未知结果锁定，普通查询不能解锁。资源或 Session generation 变化销毁实例和 Draft，迟到响应失效。公共组件使用既有 Vue/Vuetify，不引入后端页面配置或新的业务规则。

版本档案页分别读取正式资料、开放候选与所选历史，不以候选覆盖正式版本。公共明细、详情、附件和历史区块只接收所辖数据与必要模式；客户子单位/定价、产品配方/单位试算和 WFL 编译试算使用有限专用区块。专用区块只持有本地交互，审批、写入、互斥和刷新由页面统一持有。历史快照保持原采用值，创建新候选时的引用解析遵循对应领域规则。附件正文通过精确授权的 typed API 读取，文件在 Draft 内保留至提交时暂存；关闭局部对话框不能解除页面级未知写入锁。WFL 实例由独立流程运行页管理，不保留第二份定义页面。

验收经过真实 definition → Registry/Resource Host → 用户操作 → 类型化 API，不导出私有状态供测试。每片删除替代的模板、VM、包装、导出和专属测试后独立验证；本片不执行生产部署或业务数据迁移。

单据页统一拥有全部普通 VOU 与会计期初的列表、详情、审批及 Draft 提交。VOU 保留 documentId、documentNo、handlerName、revision 与不可变 Submission，不并入版本档案状态机。销售/采购订单使用商品行、局部配方与附件，期初使用独立分类录入载荷；区块不持有最终写入或刷新回调。居间计算录入仍等待 #412 的现行算法确认；其余 31 类人工录入已有实现，不能据此声明整批 DP-01–12 验收完成。

配置页拥有当前映射的 revision、保存和结果核实；条件规则与凭证模板属于局部映射区块，只接受所辖值、目录及禁用模式，并复用公共表单。现有映射协议在保存时执行领域校验，没有独立试算动作。未知保存保留原输入与锁，关闭局部编辑器或普通查询不能解除；显式读取只有确认当前值匹配该请求且 revision 已推进后才解除。

报表页直接消费受约束参数及列定义，保留 hasMore 分页和导出权限语义。流程运行页持有实例、节点动作及审计；动作资格交集服务端集合与精确权限，正文仍从 VOU 读取。未知节点动作仅以同一 requestKey 的审计证据确认，历史同类动作不能作为此次写入证据。
