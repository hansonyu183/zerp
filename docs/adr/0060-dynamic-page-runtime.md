# 动态页面拥有交互生命周期

逐页编辑器重复管理请求、权限和刷新，使相同操作产生不同语义。按 #408、#409、#410，已登记 APP/AUX、五类 BOB 版本档案及 WFL 流程定义资源只提供一个强类型 definition，包含资源身份、有限字段及无状态类型化数据适配；直接维护页或版本档案页在实例内拥有查询、编辑、动作互斥、反馈和刷新。基础列、关键词、分页和弹窗采用运行时默认值。Registry 直接绑定定义，不保留仅转发参数的页面包装。

本决定部分替代 [ADR-0052](0052-session-dynamic-navigation-and-page-migration.md) 中逐页 VM、专有字段编辑器及页面交互回调的条款；保留其 Session、精确授权、强字段契约、查询快照、异步隔离和本地 Draft 生命周期。其他领域随后按单据、配置、报表和流程运行职责分别迁移，尚未迁移的资源维持现有入口。

字段仅访问顶层键，复用有限值语义并增加实际消费者需要的多行文本、密码、多选及有限条件显示。筛选和编辑分别提交；定义不接受任意路径、组件、模板、脚本或表达式。引用绑定有限真实授权来源，各字段请求独立隔离，完整保留既有关联；候选采用和委派上限仍由领域服务校验。

运行时只通过类型化 API 适配查询与写入。取消不刷新，确认写入成功刷新一次，刷新失败不重放；未知结果锁定，普通查询不能解锁。资源或 Session generation 变化销毁实例和 Draft，迟到响应失效。公共组件使用既有 Vue/Vuetify，不引入后端页面配置或新的业务规则。

版本档案页分别读取正式资料、开放候选与所选历史，不以候选覆盖正式版本。公共明细、详情、附件和历史区块只接收所辖数据与必要模式；客户子单位/定价、产品配方/单位试算和 WFL 编译试算使用有限专用区块。专用区块只持有本地交互，审批、写入、互斥和刷新由页面统一持有。历史快照保持原采用值，创建新候选时的引用解析遵循对应领域规则。附件正文通过精确授权的 typed API 读取，文件在 Draft 内保留至提交时暂存；关闭局部对话框不能解除页面级未知写入锁。WFL 实例独立保留现有运行入口，不保留第二份定义页面。

验收经过真实 definition → Registry/Resource Host → 用户操作 → 类型化 API，不导出私有状态供测试。每片删除替代的模板、VM、包装、导出和专属测试后独立验证；本片不执行生产部署或业务数据迁移。
