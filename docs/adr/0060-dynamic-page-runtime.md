# 动态页面拥有交互生命周期

逐页编辑器重复管理请求、权限和刷新，使相同操作产生不同语义。按 #408–#413，已登记 APP/AUX、五类 BOB 版本档案、WFL 流程定义、VOU、ACC 映射、RPT 报表及 WFL 实例资源只提供一个强类型 definition，包含资源身份、有限字段及无状态类型化数据适配；六类动态页面在实例内拥有查询、编辑、动作互斥、反馈和刷新。基础列、关键词、分页和弹窗采用运行时默认值。Registry 直接绑定定义，不保留仅转发参数的页面包装。

本决定部分替代 [ADR-0052](0052-session-dynamic-navigation-and-page-migration.md) 中逐页 VM、专有字段编辑器及页面交互回调的条款；保留其 Session、精确授权、强字段契约、查询快照、异步隔离和本地 Draft 生命周期。配置页只接受 ACC 映射定义，报表页接受报表编码定义，流程运行页接受 WFL 实例定义；类型化适配保持现有协议，有限资源不增加可配置回调。

字段仅访问顶层键，复用有限值语义并增加实际消费者需要的多行文本、密码、多选及有限条件显示。筛选和编辑分别提交；定义不接受任意路径、组件、模板、脚本或表达式。引用绑定有限真实授权来源，各字段请求独立隔离，完整保留既有关联；候选采用和委派上限仍由领域服务校验。

运行时只通过类型化 API 适配查询与写入。取消不刷新，确认写入成功刷新一次，刷新失败不重放；未知结果锁定，普通查询不能解锁。资源或 Session generation 变化销毁实例和 Draft，迟到响应失效。公共组件使用既有 Vue/Vuetify，不引入后端页面配置或新的业务规则。

版本档案页分别读取正式资料、开放候选与所选历史，不以候选覆盖正式版本。公共明细、详情、附件和历史区块只接收所辖数据与必要模式；客户子单位/定价、产品配方/单位试算和 WFL 编译试算使用有限专用区块。专用区块只持有本地交互，审批、写入、互斥和刷新由页面统一持有。历史快照保持原采用值，创建新候选时的引用解析遵循对应领域规则。附件正文通过精确授权的 typed API 读取，文件在 Draft 内保留至提交时暂存；关闭局部对话框不能解除页面级未知写入锁。WFL 实例由独立流程运行页管理，不保留第二份定义页面。

验收经过真实 definition → Registry/Resource Host → 用户操作 → 类型化 API，不导出私有状态供测试。每片删除替代的模板、VM、包装、导出和专属测试后独立验证；本片不执行生产部署或业务数据迁移。

单据页统一拥有全部普通 VOU 与会计期初的列表、详情、审批及 Draft 提交。VOU 保留 documentId、documentNo、handlerName、revision 与不可变 Submission，不并入版本档案状态机。销售/采购订单使用商品行、局部配方与附件，期初使用独立分类录入载荷；区块不持有最终写入或刷新回调。居间计算消费持久化动态脚本，具体公式不是 #412 录入能力的开发前置条件；公共运行时拥有来源读取、计算和提交，局部区块只编辑及展示所辖数据。该链路与全部 32 类人工录入的实现及验收证据见 [2026-09-09 整改记录](../testing/dynamic-pages-review-fixes-2026-09-09.md)；验收结论以该记录列明的范围和结果为准。

配置页拥有当前映射的 revision、保存和结果核实；条件规则与凭证模板属于局部映射区块，只接受所辖值、目录及禁用模式，并复用公共表单。现有映射协议在保存时执行领域校验，没有独立试算动作。未知保存保留原输入与锁，关闭局部编辑器或普通查询不能解除；显式读取只有确认当前值匹配该请求且 revision 已推进后才解除。

报表页直接消费受约束参数及列定义，保留 hasMore 分页和导出权限语义。流程运行页持有实例、节点动作及审计；动作资格交集服务端集合与精确权限，正文仍从 VOU 读取。未知节点动作仅以同一 requestKey 的审计证据确认，历史同类动作不能作为此次写入证据。

## 字段与录入操作（#416）

公共 FieldInput 是唯一普通控件选择与呈现入口，不创建 form；FormBlock 组合所辖顶层字段、类型化引用与递归 rows 子项，EditForm 只拥有编辑提交事件，DynamicForm 只拥有筛选范围、规范化与显式查询。局部明细使用 FormBlock，不创建提交表单。金额和数量保持字符串，整数未完成输入保留至提交校验；空值、0 和 false 分别处理。条件可见与只读字段不改变原有有效值集合。IME 选词不触发提交。

ID 候选、历史快照及单据来源采用保持各自适配和精确权限；共享基础呈现不接管候选加载、分页或业务采用。产品单位等必填空快照由对应业务字段声明提供，公共表单不引用业务数据工厂。RPT 参数使用有限无状态适配，保留日期范围数组协议、原参数校验与仅导出资格。ACC 条件匹配值的自由值集合保留局部组合框；它维护条件值集合，不承担编辑提交。

本片固定动作直接从有限语义映射选择既有 MDI 图标，保留短中文；保存与提交、删除与移除分别表达持久化与局部编辑意图。装饰图标不重复朗读，按钮在桌面与 390px、明暗主题中保持可操作。列表与导航图标、复杂页面职责拆分不在本片扩展。验收见[字段与录入操作](../use-cases/field-entry.md)。

## 列表与导航（#417）

公共 DynamicCols 统一普通列表的表头、有限类型单元格、加载、空态和行操作，复用 ListSurface：视口小于 600px 时显示字段名与值组成的卡片，其余显示表格。卡片与表格使用相同数据和操作入口。业务嵌套结果经无状态适配成为顶层展示行；列不接受深层路径、格式回调、组件或查询能力。正式版本使用 objectId，提交记录使用 subjectId，单据使用 documentId，流程使用 processId；报表使用显式本页展示键，不增加 wire 身份。报表保留可见列、列宽和原返回值解释。复杂历史和明细不接入 CRUD 生命周期。

ListPageShell 只接展示数据、筛选输入和事件，直接维护页持有初始化、引用加载、卸载、写入、反馈与删除确认。分页明确区分 total 与 hasMore，查询快照、乱序响应、写后一次刷新及未知写入锁仍由六类运行时拥有。

Registry 必须登记 definition，不登记 component；Host 按 definition.kind 闭合选择六类页面并传入对应定义，资源与 Session 切换仍销毁页面实例。行操作仅展示服务端动作与精确权限交集，不由图标推断资格。

行操作只显示统一有限语义图标，中文名称用于提示与无障碍标签；图标未登记属于字段契约错误。固定动作内部选择统一有限语义图标。导航呈现层从已知领域与资源选择图标，动态报表使用报表语义；未知项无图标仍可导航。无法自行推断语义的通用动态项允许单个可选 icon 语义键，列表通过条目元数据承载，不重复增加容器参数；类型与运行时均拒绝任意库字符串、组件、SVG、URL 和样式。短中文、装饰图标、仅图标控件的可访问名称与悬停/聚焦提示保持一致。验收见[列表与导航](../use-cases/list-navigation.md)。

## 复杂页面内部职责（#418）

单据的创建、克隆与载荷转换集中在页面私有的封闭 Draft 判别联合中；编辑组合仅分派所辖 Draft，详情组件只呈现不可变 Submission。提交身份、审批、未知结果、写入与刷新仍由页面实例拥有。居间计算的输入、脚本编辑与结果分别呈现，页面协调来源读取、试运行及脚本保存；脚本保存与单据提交分别保留精确未知请求身份，关闭编辑区块不清除这些身份。

版本页的列表、候选编辑、历史详情分别接收所需展示值和有限意图。正式资料、开放候选、所选历史及审计保持独立，业务适配继续使用强类型方法。公共表单、引用、附件和通用详情归公共职责目录，客户、产品及 WFL 专用能力仍归各自业务区块。

局部 pending 按真实操作来源聚合；任一来源结束不能解除另一来源的阻塞。关闭编辑实例使其迟到响应和 pending 事件失效，重新打开时使用新实例。固定编辑、审批、历史、附件与试算意图使用统一图标，保留中文无障碍名称、精确权限和必要确认；行操作不附可见文本。验收见[复杂页面职责与集成](../use-cases/complex-page-boundaries.md)。

## 响应式筛选与递归子项

DynamicForm 默认显示定义顺序中的前两个筛选字段；不足两个则全部显示，日期范围计为一个字段。其余字段在“更多条件”下展开，折叠后不清空，查询仍规范化并提交全部字段；入口显示隐藏区域的已填写条件数，0 和 false 属于已填写。日期范围使用统一输入区域和日期选择浮层，保留起止单边、同日、清空与范围顺序校验，展开和改值不触发查询。公共表单控制字段间距为 16px，页面不逐项补间距。导航菜单按钮保留无障碍名称，不显示“切换导航”提示浮层。

查看和编辑表单中的对象数组通过 CollectionBlock 复用 ListSurface；摘要字段由类型化定义提供，未指定时使用前四个适合摘要的字段，完整字段在子项弹窗显示。FormBlock 的 rows 字段与 DetailsBlock 的 rows 字段递归复用此路径；枚举多选与附件继续使用专属控件。专用明细编辑器只接收单条草稿及必要上下文，使用同一公共列表与弹窗，不持有最终提交或刷新。

每层编辑弹窗复制独立草稿，确定后只更新上一层，取消丢弃本层及已确认的下层修改。新增、移除与编辑仍随父表单最终提交；子项不产生独立业务写入。取消局部编辑器释放其待处理状态并使迟到读取失效，不能解除页面级未知写入锁。异步读取未完成时不能确认子项或提交父表单。子单位最少条数、各单据明细上限和精确维护权限继续由原有规则决定。手机端子项弹窗全屏，关闭后恢复上一层焦点。
