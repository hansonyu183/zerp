# WFL 业务流程领域

## 1. 领域边界

WFL 管理单据组合、事件订阅、跨单据业务规则和自动建单。原子单据的正文、生命周期、附件和单据审计均属于 VOU；WFL 不代理这些能力，也不以流程角色、流程归属或控制域实施授权。

当前流程仅有：

- `SALES_FULFILLMENT`（销售履约）；
- `PURCHASE_FULFILLMENT`（采购履约）。

居间贸易流程及其五类专用单据已物理删除。

## 2. 单据组合

每张 VOU 单据只保存可空的 `parentEntity + parentDocumentId` 直接上级。分支、汇聚、阶段顺序和流程实例链接保存在 WFL。流程详情只返回单据链接摘要；读取正文必须另行通过对应 `/vou/{entity}/get` 权限。

VOU 在原事务中发布创建、保存、状态变化和删除事件。WFL 同步订阅事件并在同一事务中：

- 创建或更新流程实例和阶段链接；
- 幂等生成销售出库、销售送货和销售签收；
- 校验累计数量、上下级状态、短结限制；
- 在全量履约后自动完成，在撤销履约后重新打开。

任何订阅失败都会回滚触发它的原子单据事务。

## 3. API 与权限

销售履约和采购履约仅公开以下流程级动作：

- `query`
- `get`
- `audit-history`
- `short-close-request`
- `short-close-cancel`
- `short-close-confirm`
- `short-close-unconfirm`

原子单据的新建、保存、删除、核对、批准、最终处理、附件和审计只调用 VOU API，并逐动作校验精确的 VOU 权限。流程页面不能借助 WFL `get` 绕过 VOU `get` 权限读取正文。

`query` 返回专用的销售或采购流程列表响应。每项包含根单号、业务日期、客户或供应商、币种金额、流程状态、当前阶段、更新时间、KG 紧凑摘要，以及按产品计量单位分组的履约汇总。同一计量单位内合并不同产品，并返回去重后的产品数；不同单位严禁相加。紧凑摘要排除包装物，并使用根订单行保存的换算比例统一为 KG；原单位完整指标保持可展开。列表读取采用分页根单查询和固定次数的批量汇总查询，不得逐流程调用 `get`，数据库查询次数不得随列表行数增长。

## 4. 销售履约

销售订单创建后建立销售履约组合。阶段为销售订单、生产、销售出库、销售送货、销售签收、销售退货。
显式创建的生产配货单以 `PRODUCTION` 阶段加入同一组合，仅用于关联展示和追溯，不参与
履约完成状态计算，也不阻断销售出库。
三类正向下级单据没有公开创建 API，由事件订阅按直接上级关系幂等生成。签收发生拒收时
幂等生成 `REFUSAL` 销售退货草稿；签收后允许从签收单或履约页创建 `AFTER_SALE` 退货。

累计出库、送货和签收数量不得超过上级数量。全部数量完成后流程自动完成；反最终处理会重新计算并按需重开。存在未完成下级单据时禁止短结。

退货单按根销售订单加入同一流程，每条明细追溯具体签收行。已完成或已短结的流程存在
未完成退货时显示 `RETURNING`；退货最终处理或人工草稿删除后恢复原终态。尚未终结的正向
履约不因退货停止，但未完成退货会阻止短结。

销售列表的每个计量单位组展示订购、出库处理中、累计完成出库、在途、已签收、拒收、损耗和待履约数量。拒收退回与售后退货分别统计处理中和已完成数量。`净签收 = max(已签收 - 已完成售后退货, 0)`；拒收不计入已签收，拒收退回也不从净签收重复扣减。`在途 = max(已完成出库 - 已完成签收结果中的签收、拒收和损耗, 0)`；待履约沿用订单履约口径，只扣已签收与在途，拒收和损耗仍需继续履约。

销售紧凑摘要依次显示 `缺货 / 出库 / 在途 / 签收`。出库和签收均为相应节点已完成单据的累计数量，退货不冲减这两个累计数。缺货按仓库和产品查询时计算：当前库存先扣除更早的有效销售订单未出库需求，再分配给当前订单；优先级为业务日期升序、单号升序。只有已批准且未完成、未短结的销售流程消耗承诺库存；草稿和已核对订单只做在已有承诺之后的假设计算。没有可确定仓库的历史订单不展示缺货数。

## 5. 采购履约

采购订单创建后建立采购履约组合，阶段为采购订单、采购入库、采购退货。采购入库可以通过
VOU API 人工创建，必须以已批准且未短结的采购订单为直接上级。允许分批、部分商品入库；
所有未删除入库单累计数量减已最终处理退货数量不得超过订单数量。

采购订单不记账；采购入库最终处理按实际数量写库存与应付，采购退货最终处理反向写库存与
供应商往来。退货单直接归属根采购订单并追溯具体入库行。已完成或已短结流程存在未完成退货时
显示 `RETURNING`；退货完成后按净入库量重新打开流程并清除短结信息。存在未完成入库或退货单时
禁止短结。

采购列表的每个计量单位组展示订购、入库处理中、累计入库、退货处理中、已退货、净入库和剩余可入库数量。`净入库 = max(累计入库 - 已退货, 0)`；剩余可入库沿用占用口径，以全部未删除入库单作为占用，并仅由已完成采购退货释放数量。
采购紧凑摘要依次显示 `订购 / 累计入库 / 退货中 / 净入库`，均换算为 KG；退货中只统计尚未完成的采购退货，净入库只扣已完成退货。

## 6. 审计与验收

流程审计只记录组合、自动建单、状态推导和短结事件，不复制 VOU 单据审计。验收至少覆盖事件事务回滚、重复事件幂等、并发超量保护、自动完成与重开、未完成子单短结阻断，以及流程详情的 VOU 权限边界。
