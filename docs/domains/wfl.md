# WFL 业务流程领域

## 1. 领域边界

WFL 管理单据组合、事件订阅、跨单据业务规则和自动建单。原子单据的正文、生命周期、附件和单据审计均属于 VOU；WFL 不代理这些能力，也不以流程角色、流程归属或控制域实施授权。

当前流程仅有：

- `SALES_FULFILLMENT`（销售履约）；
- `PURCHASE_FULFILLMENT`（采购履约）。

居间贸易流程及其五类专用单据已物理删除。

## 2. 单据组合

每张 VOU 单据只保存可空的 `parentEntity + parentDocumentId` 直接上级。分支、汇聚、阶段顺序和流程实例链接保存在 WFL。流程详情只返回单据链接摘要；读取正文必须另行通过对应 `/vou/{entity}/get` 权限。

VOU 在原事务中发布创建、保存、状态变化和删除事件。WFL 同步订阅事件并在同一事务中：

- 创建或更新流程实例和阶段链接；
- 幂等生成销售出库、销售送货和销售签收；
- 校验累计数量、上下级状态、短结限制；
- 在全量履约后自动完成，在撤销履约后重新打开。

任何订阅失败都会回滚触发它的原子单据事务。

## 3. API 与权限

销售履约和采购履约仅公开以下流程级动作：

- `query`
- `get`
- `audit-history`
- `short-close-request`
- `short-close-cancel`
- `short-close-confirm`
- `short-close-unconfirm`

原子单据的新建、保存、删除、核对、批准、最终处理、附件和审计只调用 VOU API，并逐动作校验精确的 VOU 权限。流程页面不能借助 WFL `get` 绕过 VOU `get` 权限读取正文。

## 4. 销售履约

销售订单创建后建立销售履约组合。阶段为销售订单、销售出库、销售送货、销售签收、销售退货。
三类正向下级单据没有公开创建 API，由事件订阅按直接上级关系幂等生成。签收发生拒收时
幂等生成 `REFUSAL` 销售退货草稿；签收后允许从签收单或履约页创建 `AFTER_SALE` 退货。

累计出库、送货和签收数量不得超过上级数量。全部数量完成后流程自动完成；反最终处理会重新计算并按需重开。存在未完成下级单据时禁止短结。

退货单按根销售订单加入同一流程，每条明细追溯具体签收行。已完成或已短结的流程存在
未完成退货时显示 `RETURNING`；退货最终处理或人工草稿删除后恢复原终态。尚未终结的正向
履约不因退货停止，但未完成退货会阻止短结。

## 5. 采购履约

采购订单创建后建立采购履约组合。采购入库可以通过 VOU API 人工创建，必须以已批准且未短结的采购订单为直接上级。允许分批、部分商品入库，所有未删除入库单累计数量不得超过订单数量。

采购订单不记账；采购入库最终处理按实际数量写库存与应付，反最终处理追加反向流水。全部入库后自动完成，撤销入库后重新打开。存在未完成入库单时禁止短结。

## 6. 审计与验收

流程审计只记录组合、自动建单、状态推导和短结事件，不复制 VOU 单据审计。验收至少覆盖事件事务回滚、重复事件幂等、并发超量保护、自动完成与重开、未完成子单短结阻断，以及流程详情的 VOU 权限边界。
