# 会计期初迁入 VOU

受控环境执行 `pnpm --filter @zerp/api migrate:vou-opening`。连接与生产范围确认沿用现有运行配置；本命令不部署、不重建数据库、不清理其他领域事实。执行前停止旧 API 写入，转换成功后启动包含 VOU 期初入口的版本，再正常同步权限目录。

迁移在单个事务锁定期初、审批、账簿及权限相关表，验证每账簿唯一期初、无 versionNo、主体与快照身份一致。保持 bookId、Approval Entry ID、快照、会计事实、精确引用及事件 ID，仅把期初归属从 acc 改为 vou，补充账簿唯一索引和提交幂等记录。

旧 `/acc/opening/query` 转为 `/vou/opening/query` 与 `/vou/opening/get`；submit-new、approve、reject、unreject、unapprove、delete 一对一转换。新增 audit-history 不自动授予。未转换前普通目录同步拒绝删除旧期初授权。转换后只提供 VOU 当前入口。

历史幂等指纹以原提交人和已保存的规范化快照建立；旧客户端未保存的原始输入无法还原，不能据此重放旧请求。身份冲突、重复幂等键或不合法历史返回 blocker 并整体回滚，不自动选择候选、改写余额或批准提交。成功后再次执行不重复迁移。

回读验证：旧 acc/opening Entry 与授权为零；每账簿最多一个期初；原 Entry、快照、审计与 OPENING 凭证关联保持。通过有权人员打开 VOU 页面验证查询、账簿范围与只读历史。本次实现的验收不对在线数据执行此迁移。
