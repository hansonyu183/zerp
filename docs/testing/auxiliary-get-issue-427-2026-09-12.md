## 发现与修复

- 真实 Vuetify 测试先复现聚焦时错误发出旧名称搜索；改为实际输入事件与显式清空后通过，避免翻页关键词被程序性事件清空、候选被重载移除。
- 浏览器仓库选择暴露持久化快照误按创建输入解析的问题。AUX assets 回归先以 `validation_failed` 失败，复用已有持久化解析后，仓库、资金账户、车辆及员工候选通过。
- 独立 Spec 审查发现成功 `null` 订单历史被通用响应解包拒绝；已修复并通过真实推导客户端测试。候选错误按稳定 errorKey 显示中文，网络异常提供中文重试提示。
- 真实数据库测试复现最近销售订单错误使用 `counterparty` 字段而返回空结果；按实际 `customerSubunit` 持久化字段修复后，命中及客户不匹配回归通过。
- 显式复制单据与盘点账面预览仅提供产品 ID，先读取当前实体候选、再精确 resolve；已有版本不回退。Host 测试保留录入事实，并验证无 CSRF 仍可采用盘点产品单位。历史配方材料没有版本身份时仍要求显式清除、重新选择；销售/采购新建和复制真实提交通过。
- 全套浏览器测试还复现角色已选项在远程搜索返回前被点击、节点被更新替换的同步问题；测试改为等待对应 GET 关键词与成功包络，再操作候选，保持原多选、授权及撤销断言。运行时代码未改。
- 期初浏览器账簿定位同步到公共字段的“编码 · 名称”显示，并检查 `/acc/book/options` 返回目标账簿；零期初、反批准后显式重录、借贷平衡与移动端真实提交均通过。
- Standards 审查发现角色编辑资格与正式用户保存依赖不一致；恢复既有写入资格，并明确辅助 GET 与正式写入授权的区别。最终 Standards 与 Spec 均无未解决 finding。
