# 动态页面复核修复与居间计算验收

本轮基于 `a8b08ddb` 修复动态页面复核发现。通用页面修复已提交为 `3de1d9c8`；居间计算实现与本记录位于同一后续提交。范围包括本地实现、测试和提交，不包含生产发布或业务数据转换。

## 修复范围

- 版本档案提交结果未知时，读取 `approval_not_found` 不再解除原提交锁；保留原输入和身份等待核实。
- 新建单据统一采用上海业务日期，覆盖 UTC 跨日及月末边界；库存盘点账面查询权限显示中文。
- 居间计算接入公共 DocumentPage：读取、维护、试运行并保存持久化全局脚本，取得后端月度来源，显式重新计算，提交及回读冻结快照。没有发布默认公式，测试脚本仅用于独占测试库。
- 后端校验来源哈希、脚本 revision、同月唯一、明细与汇总一致性；历史结果保持采用时快照。控制账簿锁内重验来源，月末关账要求逐月已批准计算。
- 来源覆盖回款 FIFO、零金额签收、退货累计分摊、订单采用时产品计件口径及跨月冲回。不同历史版本或名称的同一收款方按稳定身份汇总，汇总引用必须来自该组真实采用快照。
- ACC 提供五类居间汇总集合及非负计提/冲回金额字段，支持对应费用和其他应付的正反分录。
- 脚本保存超时后保留发送内容与 revision；读取旧版或空值不解锁，只有确认本次写入快照后才能继续。

权威规则与页面路径见 [VOU](../domains/vou.md#24-居间计算单)、[ACC](../domains/acc.md) 和[单据用例](../use-cases/vou/catalog.md)。

## 已验证的公开行为

`vou-intermediary.int.test.ts` 使用真实 PostgreSQL 与领域服务验证：脚本首次配置、revision 冲突、权限拒绝、来源哈希伪造拒绝、同月重复拒绝、后续脚本变化不改写历史，以及来源变化导致原稿批准失败。

真实销售链路以订单、出库、配送和签收生成来源。10 基准数量除以采用时包装规格 3 得到 `3.333333` 件；零金额签收退回 1 后为 9 数量、3 件，后续产品改版不影响这些事实，员工改名后来源与提交快照仍保留原采用姓名。非零签收未收款时不进入来源，按客户子单位分配的实际收款入账后按收款日进入来源；未记账退货不减少来源。零金额场景批准 3 元收益，实际核对费用借方、员工应付贷方；次月退货按原计提比例冲回 0.33 元，实际核对相反分录，后续批准冲回阻止原计算单反批准。

公开 ResourceHost 测试覆盖未计算不能提交、试运行后保存、保存后显式重算、提交采用快照，以及未知脚本保存的旧读取保持输入与锁。运行器测试覆盖无宿主能力、执行超时后恢复、异步结果拒绝及改变公式产生不同结果。共享结果测试覆盖稳定收款方跨历史快照归组、来源/金额一致性与负数冲回。
