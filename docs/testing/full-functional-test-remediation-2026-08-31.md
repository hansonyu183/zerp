# ZERP 全量功能测试整改矩阵

## 1. 文档定位

本文以[全量功能测试报告](./full-functional-test-2026-08-31.md)为原始证据，记录整改决策、实现位置和复验结果。原报告中的复现现象、严重度和测试数据保持不变；规格冲突通过本矩阵重新定性，不回写原始结论。

状态约定：

- `已实现`：规格、契约和代码已完成，相关自动化测试通过。
- `重新定性`：原现象与权威领域规则一致，已补足产品或文档表达。
- `待内测复验`：本地隔离环境已验证，仍需在发布后的线上内测环境复验。
