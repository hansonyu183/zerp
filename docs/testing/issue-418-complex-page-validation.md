## 实现与行为回归

单据 Draft 的创建、克隆和载荷转换集中在 `document-page/draft.ts` 的封闭联合中；DocumentFields 只组合所辖值，DocumentSnapshot 呈现不可变提交。居间计算输入、脚本和结果分别呈现，由 DocumentPage 协调读取、试运行、保存、提交与核实。

版本页分别采用 VersionLists、CandidateFields 和 VersionSnapshot 呈现列表、候选与历史；运行时继续拥有正式资料、候选、所选历史、审计和强类型写入适配。公共附件迁至 `components/attachments/`，通用详情迁至 `components/details/`，明细表单迁至 `components/dynamic-fields/`，所有导入同步更新，旧路径和 IntermediaryBlock 已删除。

新增回归经真实 ResourceHost 验证：脚本未知保存关闭后仍保留页面锁与核实入口，网络失败、`internal_error`、`invalid_response` 均不丢请求身份；精确核实成功清空旧计算，重新计算后才可提交。两个独立附件读取中一项完成仍阻止提交，关闭候选后迟到读取不污染新候选。历史默认经营主体按原始 ID 比较，展示名称不改变差异判断。审批及反向审批经真实 Vuetify 验证图标、短中文、装饰图标属性、禁用资格和精确动作事件。
