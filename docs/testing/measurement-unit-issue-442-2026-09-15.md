## 关键验收事实

- 单位管理的桌面和 390px 页面无独立符号、逐单位精度输入或精度筛选；固定系数创建、修改、查询、启停和回显正常。
- 产品页面采用 kg/1、吨/1000，`1000 kg` 与 `1 吨` 均试算为基本数量 `1000`；固定系数不可在产品覆盖。产品专属桶系数仍可编辑，数据库覆盖产品 A 的 200 与产品 B 的 180，浏览器验证专属换算和超安全整数的大数精确试算。
- 订单只在明确采用建议后写入基本数量；输入 `1.234` 不产生建议并被前后端业务边界拒绝，`1.23` 保留。单价、系数、已确认基本数量和底层计算精度沿用原规则。
- current 单位变化不覆盖旧产品及交易快照。历史产品/同客户订单配方原样采用保持 `1.234567` 等原值，手工修改超两位则拒绝；订单生产继承原数量，自动领料建议保留计算精度。
- 转换集成测试从旧 schema 开始，验证固定比例冲突、不完整快照及基线漂移均拒绝；事务末端故障完整回滚；产品、待批 Submission、VOU 行和配方的数量/价格原值保留，历史高精度产品可继续批准。
