## #456 行为与回归

- 新增维护 query 独立权限和 20 条分页，覆盖关键词、启用/有效性、停用及无效定义；摘要不含 SQL。get/save/query 与 query/export 分别精确授权，服务端返回维护动作资格，不自动授予普通角色。
- 公共 ConfigurationPage 持有编辑与写入，参数、枚举选项、结果列使用公共子项编辑器。八类参数、七类列类型及十四类引用源有闭合中文映射。组件验证所有类型及可选格式/下钻回填，取消下钻、清空默认值均经过真实子项编辑器保存。
- SQL 及零行元数据验证、revision 冲突和失效修复复用现有领域服务。新建 ID 只生成一次，字符串 revision 不转数字；非法保存保留输入，未知结果不重放，保存成功与列表/目录刷新失败分开反馈。
- Session 持有目录请求代次与 generation。任意名称供菜单、面包屑、正文共享，资格仍由 apiPaths 决定。覆盖目录失败/重试/不可用、无授权目录项、新旧改名乱序、账号替换和强制改密清理；仅导出页不自动查询。
- 公共直接维护、会计映射、报表查询/导出及 Session/导航通过现有组件套件回归。维护编辑的默认值清空、空有效性筛选均保留先失败再修复的回归测试。
- RPT 既有集成夹具补清理 AUX 审计记录；浏览器夹具清理本次报表维护者新建定义及相关权限，避免悬挂用户引用。
