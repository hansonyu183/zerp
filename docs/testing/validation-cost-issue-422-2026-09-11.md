## 测量口径

同一 Apple Silicon Mac，Node 26.5.0、pnpm 10.34.5、Go 1.26.6、Docker Engine 29.2.1；两轮均从没有 Target 容器开始，使用同一可丢弃 `zerp-target` 拓扑、串行测试和默认端口。没有清空工具与镜像构建缓存，因此安装、构建、CPU 调度和浏览器交互的墙钟时间只能作为本轮观测，不能推导稳定提速比例。

基线执行原 `make target-e2e`，候选执行 `make e2e`。候选额外包含原基线入口未执行的公共/CI 检查和新增编排 CLI 回归；比较表分别列出相同重型阶段。使用临时 Python subprocess 包装 Make，以 monotonic 时钟给每行输出加时间戳，按根级阶段命令的开始/结束计算墙钟时间；不读取私有测试状态，不引入常驻测量或监控服务。

“生成”不含单列的数据库准备；“Compose 构建/健康”包含依赖层、镜像构建和首次 API/Web 健康等待；浏览器阶段包含 fixture 初始化、Playwright 执行和清理。后四组在各自独立数据库中串行运行，数据库准备不与浏览器阶段混算。
