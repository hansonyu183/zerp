## 居间计算单：本轮延期

`/vou/intermediary-calculation` 的页面入口已存在，但本轮不将它计入已完成的页面恢复或 E2E 验收。

当前后端没有来源生成、脚本读取/保存或脚本执行的可执行契约；领域服务也不会重算并核验来源/脚本 hash、结果、票据分配和汇总。现有通用 VOU 写入只持久化客户端提交的快照，不能作为居间计算引擎的替代品。

后续必须以独立垂直切片交付：来源事实归属与确定性生成、revisioned 脚本契约及执行、持久化关系和保存/复核/批准的过期校验、专用页面动作，以及公共接口/集成/浏览器 E2E。不得以空来源、伪造 hash 或前端推断绕过这些领域规则。
