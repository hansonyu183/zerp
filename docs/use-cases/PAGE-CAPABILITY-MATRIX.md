# 当前页面能力矩阵

## 范围与判定规则

本矩阵逐项登记当前 `frontend/src/target/router/index.ts` 的 **80 个带 `meta.title` 的正式路由**及与其一一对应的 **80 份页面用例**。原始页面和视觉来源仍以基线提交 `f856118fdc3304cf1a5d713094645317cec58fb2` 为比对起点，但路由、组件、用例和测试列只记录当前仓库事实。

- 正式路由/组件：以当前 `frontend/src/target/router/index.ts` 的登记和导入为准。旧 `target-probe.vue` 与巨型 `target/vm.ts` 已删除，不再作为任何页面的实现或测试入口。
- 契约缩写均为当前可执行 Hono/Zod 源，动作族见下表；`后端缺失` 仅在没有相应可执行契约时使用。
- 用例：以路由 `meta.useCaseKey` 指向的 `docs/use-cases/<domain>/<page>.md` 为准；当前统计由生成文件 `COVERAGE.md` 交叉核对。
- 自动测试：主矩阵“自动测试/测试”列登记单元、Router 或 API 集成覆盖；所有页面 E2E 入口及其路由映射在后文逐组列出。执行结论区分真实浏览器流程与仅单元/Router 覆盖，不以源码存在代替验收。
- 视觉证据：`restoration-visual.spec.ts` 在 `.scratch/frontend-restoration/visual/` 采集当前桌面与窄屏渲染；它验证源码还原后的当前页面，**不做基线像素等价断言**。主表“未采集”只表示该路由没有本轮截图，不表示页面未实现或没有 E2E。
