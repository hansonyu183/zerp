# 基线页面能力矩阵

## 范围与判定规则

本矩阵记录基线提交 `f856118fdc3304cf1a5d713094645317cec58fb2` 中 `frontend/src/router/registry.ts` 的 68 个有限页面登记项，供后续页面切片逐项闭环。它不是当前功能清单，**可调用的 Hono 契约或 probe 分支不等于正式页面已交付**。

- 正式路由/组件：以当前 `frontend/src/target/router/index.ts` 实际登记为准；已恢复的 AUX 页面在下表逐项标为正式路由，尚未进入后续切片的页面仍保持“未登记 / 无”。
- probe 分类：是 `frontend/src/target/api.ts:26-38`、`frontend/src/target/vm.ts:509,524-538,650-702,3355-3367` 的迁移候选能力，不能作为页面存在的证据。
- 契约缩写均为当前可执行 Hono/Zod 源，动作族见下表；`后端缺失` 仅在没有相应可执行契约时使用。
- 用例、测试和视觉证据：只有对应切片交付并验证后才能改为完成状态。
