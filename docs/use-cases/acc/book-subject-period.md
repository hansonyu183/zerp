# 账簿、科目与期间维护

## 页面与依据

资源 `acc/book`、`acc/subject` 由公共 DirectPage 承载，`acc/period` 由公共 ConfigurationPage 承载，登记于 [Registry](../../../frontend/src/target/navigation/registry.ts)。业务依据为 [ACC](../../domains/acc.md) 的账簿、访问范围、科目及期间规则；协议以 [ACC 可执行路由](../../../apps/api/src/acc/contract.ts) 及 [APP 辅助路由](../../../apps/api/src/app/independent-contract.ts) 为准。

## `ACC-BOOK-01` 账簿维护

查询后可打开只读详情；新增时选择开始月份和科目模板，编辑时展示开始月份及控制账簿标志为只读。查询人员与操作人员分别通过可搜索、分页的用户选择器维护，已有选项回显名称。根据服务端资格和精确权限呈现编辑、删除；删除前确认，引用失败显示中文 blocker。只有新增权限时保留入口，不发起无权查询。

## `ACC-SUBJECT-01` 科目维护

选择账簿并显式查询，翻页及保存后的刷新沿用已提交条件。新建或打开详情后维护编码、名称、父级、余额方向、辅助维度、库存数量核算、结算用途及启用状态。父级使用独立分页候选；详情按服务端冻结事实禁用对应字段，所属账簿不可改。保存和删除失败保留输入并展示原因，不尝试自动解除引用。

## `ACC-PERIOD-01` 期间维护

选择账簿后查询月份列表，显示中文锁定状态。仅呈现服务端返回且有精确权限的动作；确认框显示账簿和月份，提交所选行的原始 revision。成功刷新一次，失败显示中文原因及结构化冲突；普通查询不解除未知写入锁。

## 公共交互与验收

取消不写入，不刷新；错误保留输入，重复点击互斥。写成功但刷新失败明确提示成功，不重放请求。资源或会话切换销毁页面实例，迟到响应不覆盖新实例。revision 与十进制值保持字符串。桌面及 390px 使用同一列表与操作，页面无横向溢出。

验收经过真实 definition、Resource Host、类型化 HTTP 与独占 PostgreSQL：覆盖控制账簿、模板只创建时选择、人员范围分离、科目全部属性与冻结、父级循环和删除 blocker；期间覆盖首次空 revision、连续锁定及逆序解锁、未结束月份、未批准期初、业务 blocker 与失败原子回滚。公共运行时同时回归 APP、AUX 和会计映射消费者。
