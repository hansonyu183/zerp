# 会计账簿页面用例

## 范围

- 路由：`/acc/book`，由 `acc/book` 登记。
- 账簿、唯一控制账簿、建账模板与人员范围规则以 [ACC 会计账簿](../../domains/acc.md#2-会计账簿) 和 [账簿访问范围](../../domains/acc.md#3-账簿访问范围) 为准。
- 页面只使用 `/acc/book/*` 与 `/app/user/query` 可执行 Hono 路由。

## `ACC-BOOK-01` 查询与范围

1. 用户按编码或名称显式查询固定每页 20 本账簿。
2. 列表只呈现服务端在动作权限与查询范围共同校验后返回的账簿；操作范围不会扩大查询结果。
3. 迟到的旧查询响应不得覆盖较新的页码或关键词结果。

## `ACC-BOOK-02` 创建与维护

1. 创建时填写名称、说明、开始月份、基础币种，并一次性选择企业、小企业或空白科目模板。
2. 查询范围与操作范围分别选择启用用户；页面明确说明需要界面操作的用户应同时取得查询范围。
3. 保存已有账簿时携带服务端 revision，不能修改开始月份、模板、编码或控制账簿标志。
4. 创建或保存失败时保留抽屉及全部输入，不用旧响应覆盖用户内容。

## `ACC-BOOK-03` 删除

1. 控制账簿不显示删除入口。
2. 其他账簿删除携带当前 revision；存在会计事实时展示服务端 blocker 并刷新列表，不自动清理引用。

## 验收

1. 页面不允许调用方指定 `controlBook` 或账簿编码。
2. 模板只在创建时显示，且完整覆盖 `ENTERPRISE | SMALL_BUSINESS | EMPTY`。
3. 两种访问范围独立提交，已知状态不显示 wire 原码。
