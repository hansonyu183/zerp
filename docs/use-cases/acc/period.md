# 会计期间页面用例

## 范围

- 路由：`/acc/period`，由 `acc/period` 登记。
- 连续锁定、逆序解锁与全部 blocker 以 [ACC 会计期间](../../domains/acc.md#10-会计期间) 为准。
- 页面只使用 `/acc/book/query` 与 `/acc/period/{query,lock,unlock}` 可执行 Hono 路由。

## `ACC-PERIOD-01` 查询

1. 用户选择其可查询账簿后读取期间及服务端 revision。
2. 页面以锁定月份计算唯一下一月份；自然月未结束时解释原因并禁用锁定按钮。

## `ACC-PERIOD-02` 锁定与解锁

1. 锁定提交下一连续月份和已有期间 revision；新月份使用 `null` revision。
2. 解锁只提交列表中最近锁定月份及其 revision。
3. 服务端重新校验期初、未完成单据、映射、库存、试算及连续性；页面不预先伪造这些判断。
4. 动作成功或失败都刷新期间事实，失败信息在刷新后仍保留，不自动重试。

## 验收

1. 页面不提供任意历史月份直接解锁或跳月锁定入口。
2. 不在前端计算余额、库存或试算事实。
