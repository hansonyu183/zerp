# 修改密码页面用例

## 范围

- 路由：`/change-password`，由 `app/change-password` 登记，且只允许受限会话使用。
- 密码策略和会话边界以 [APP 当前用户自助接口](../../domains/app.md#54-当前用户自助接口) 为准。

## `APP-PASSWORD-01` 首次登录修改密码

1. 受限会话进入页面，输入当前密码、新密码和确认值。
2. 页面提交修改密码请求，并呈现服务端返回的校验或成功结果。
3. 成功后由会话导航规则解除受限状态；失败时保留输入以便修正。

## 验收

1. 普通未认证访问不会绕过认证边界。
2. 页面不自行实现密码策略或伪造成功结果。
