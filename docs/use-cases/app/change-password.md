# 修改密码页面用例

## 范围

- 路由：`/change-password`，由 `app/change-password` 登记，且只允许受限会话使用。
- 密码策略和会话边界以 [APP 当前用户自助接口](../../domains/app.md#54-当前用户自助接口) 为准。

## `APP-PASSWORD-01` 首次登录修改密码

1. 受限会话进入页面，输入当前密码、新密码和确认值。
2. 页面提交 `/session/user/change-password`，并呈现服务端返回的校验或成功结果。
3. 成功后清理密码输入和当前会话，再回到登录页使用新密码重新认证；失败时保留输入以便修正。

## 验收

1. 普通未认证访问不会绕过认证边界。
2. 页面以会话上下文的 `passwordMinLength` 显示最小长度提示，但不自行实现完整密码策略或伪造成功结果。
3. 关闭页面、退出或账号切换会清理全部密码输入。
