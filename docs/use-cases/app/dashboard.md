# 工作台页面用例

## 范围

- 路由：`/home/dashboard`，由 `app/dashboard` 登记。
- 待办分类、动作资格和执行时重新校验以 [APP 工作台待办](../../domains/app.md#工作台待办) 与 [Approval 动作资格](../../domains/approval.md#32-approval-action-availability) 为准。

## `APP-DASHBOARD-01` 查询和处理待办

1. 页面默认查询单据待办，可切换到资料待办，并按筛选条件重新查询。
2. 页面只渲染服务端返回的可用动作；查看和编辑跳转到服务端提供的对象链接。
3. 审批、驳回或删除完成后刷新当前待办；失败保留当前筛选和可见错误。

## 验收

1. 前端不得根据状态自行推断可执行动作。
2. 查询与动作失败不会把本地视图伪装成已完成。
