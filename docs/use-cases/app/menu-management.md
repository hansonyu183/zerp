# 菜单管理用例

## 页面范围

- 路由：`/app/menu`
- 领域规则：[菜单模板](../../domains/app.md#39-菜单模板) 与 [菜单管理接口](../../domains/app.md#510-菜单管理)
- 线协议：[OpenAPI](../../../contracts/openapi/openapi.yaml) 与 [APP Schema](../../../contracts/openapi/schemas/app.yaml)
- 全站列表、筛选和行操作规范：[前端工程约束](../../../frontend/AGENTS.md)

菜单管理页面维护草稿，不直接授予权限。页面入口和各操作按服务端返回的权限状态呈现；模板、快照、目录证据及鉴权规则只由上述领域章节定义。

## `MNU-01` 加载与查看菜单

### 前端处理

1. 进入页面后读取当前模式、目录证据、草稿、已发布快照和当前导航；加载失败时保留错误与重试入口，不以本地缓存猜测最新状态。
2. 分别清晰显示草稿与已发布快照的版本、状态和差异提示。`DEFAULT` 的默认菜单只读；已发布快照在本页只读，草稿才可编辑。
3. 菜单项的路由地址与权限代码只读。页面允许按领域规则编辑草稿分组、顺序、显示名称、图标和启停，但不允许编造路由或改变路由关联的权限。
4. 新注册路由只在草稿“其他/待归类”显示，提示管理员整理并发布；已下线路由不能作为可编辑或可发布路由继续使用。

### 后端协作与结果

页面按[菜单管理规则](../../domains/app.md#510-菜单管理)读取服务端当前状态；读取不产生页面侧写入。

## `MNU-02` 编辑并保存草稿

### 前端处理

1. 仅拥有 `/app/menu/save-business-template` 时显示编辑与“保存草稿”。拖拽、增删分组和路由、启停或修改展示信息后标记草稿为脏。
2. 离开页面、切换模式、恢复草稿或关闭有脏草稿的编辑区域前必须确认是否放弃；确认放弃后重新读取草稿，不能静默保存。
3. 保存提交加载草稿时取得的草稿版本与目录证据。成功后更新本页草稿状态和版本，但不改变已发布快照、当前模式或任何用户导航。

### 后端协作与结果

保存资格、版本、目录证据、事务和审计以[菜单管理规则](../../domains/app.md#510-菜单管理)为准。冲突时页面保留用户草稿，提示刷新后重新决定，不自动合并或发布。

## `MNU-03` 发布草稿

### 前端处理

1. 仅拥有 `/app/menu/publish-business-template` 时显示“发布”。发布前展示其将替换已发布快照、影响未来菜单读取且不自动切换当前模式的提示，必须二次确认。
2. 发布提交当前草稿版本和目录证据。成功后刷新草稿、已发布快照和当前管理员自己的导航；若当前模式为 `DEFAULT`，导航模式保持不变。
3. 页面不得向其他在线用户主动推送更新，也不提示要求他们退出重登。

### 后端协作与结果

发布语义以[菜单模板](../../domains/app.md#39-菜单模板)和[菜单管理规则](../../domains/app.md#510-菜单管理)为准。冲突时页面刷新，不自动合并。

## `MNU-04` 切换菜单模式

### 前端处理

1. 仅拥有 `/app/menu/activate` 时显示模式切换。切换到 `BUSINESS_TEMPLATE` 前展示将采用最后已发布快照、不会发布当前草稿的提示，必须二次确认。
2. 成功后刷新当前管理员自己的导航和模式状态；当前已打开页面不强制跳转。

### 后端协作与结果

模式切换的资格与状态变化以[菜单管理规则](../../domains/app.md#510-菜单管理)为准；页面成功后只按响应刷新模式和导航。

## `MNU-05` 恢复初始草稿

### 前端处理

1. 仅拥有 `/app/menu/reset-business-template` 时显示“恢复初始草稿”。恢复会丢弃当前草稿，必须二次确认；有本地脏草稿时先执行放弃确认。
2. 成功后刷新草稿版本和内容，并明确提示“恢复结果尚未发布”；已发布快照、当前模式与当前导航不变。

### 后端协作与结果

恢复资格与草稿变化以[菜单管理规则](../../domains/app.md#510-菜单管理)为准；页面明确显示恢复结果尚未发布。

## 失败、并发与验收

- 草稿保存、发布、模式切换和恢复各自发生版本或目录冲突时，保留当前编辑内容并要求刷新；不得自动重试、合并或降级为旧路由。
- 当前管理员仅在自己成功的发布或模式切换响应后刷新导航；其他用户刷新页面、新开页面或恢复现有会话时重新读取并获得最新已发布菜单，无需退出重登或撤销会话。
- 当前已打开页面不因菜单更新强制跳转。
- 验收覆盖：DEFAULT 只读；保存、发布、模式切换与恢复后的页面状态和提示互不混淆；新路由仅进入草稿；已下线路由不能导航；四项写操作的按钮、二次确认和冲突刷新独立生效。
