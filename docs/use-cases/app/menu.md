# 菜单管理页面用例

## 范围

- 路由：`/app/menu`，由 `app/menu` 登记；具备任一菜单管理动作权限即可进入，默认导航用保存业务菜单权限控制可见性。
- 默认菜单、业务菜单和当前导航规则以 [APP 菜单模板](../../domains/app.md#39-菜单模板) 为准。

## `APP-MENU-01` 配置业务菜单

1. 页面加载默认菜单、业务菜单和服务端可用路由目录。
2. 管理员添加菜单组或正式路由，维护名称、图标和启用状态后保存。
3. 保存成功后重新读取菜单；可显式启用默认或业务菜单，也可重置业务菜单。

## 验收

1. 页面只能选择服务端返回的正式路由，不接受任意地址。
2. 保存、切换和重置均携带 revision，并以读回菜单为最终结果。
