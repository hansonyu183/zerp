# 权限管理用例

## 页面范围

- 路由：`/app/permission`
- 领域规则：[权限模型](../../domains/app.md#35-权限)、[最终权限计算](../../domains/app.md#4-最终权限计算) 与 [权限目录接口](../../domains/app.md#58-权限目录)
- 线协议：[OpenAPI](../../../contracts/openapi/openapi.yaml) 与 [APP Schema](../../../contracts/openapi/schemas/app.yaml)
- 全站列表、筛选和并发请求规范：[前端工程约束](../../../frontend/AGENTS.md)

权限管理页面严格只读。权限创建、同步、启停和其他生命周期变更不在本页面发起，按[权限目录领域规则](../../domains/app.md#58-权限目录)由部署或权限来源领域的受控流程负责。

## `PER-01` 查询权限列表

### 前端处理

1. 页面入口要求当前用户拥有 `/app/permission/query`；没有该权限时由路由守卫进入“无权访问”。
2. 列表查询、筛选提交、固定 20 条分页和按权限路径升序排序直接采用全站前端工程约束。查询条件只在用户明确提交查询或应用筛选后生效，不因输入变化自动请求。
3. 列表展示权限路径、领域、实体、动作和状态。默认不限定状态，启用与停用权限均可见；用户显式选择状态筛选后只显示对应状态。
4. 页面不提供新增、编辑、启用或停用操作，也不显示来源对象、角色名单、跳转入口或生命周期审计入口。

### 后端协作与结果

查询资格和目录范围以[权限目录规则](../../domains/app.md#58-权限目录)为准；页面只展示查询响应，不发起目录生命周期变更。

## `PER-02` 查看权限只读详情

### 前端处理

1. 当前用户拥有 `/app/permission/get` 时，列表提供详情入口；没有该权限时不显示详情入口，也不得通过列表响应推断或补充详情。
2. 详情只读展示权限路径、领域、实体、动作、说明、状态和按[权限目录领域规则](../../domains/app.md#58-权限目录)计算的直接关联角色数；页面不展示具体角色名单、来源对象、跳转入口或生命周期审计。
3. 详情不提供保存、启用、停用或同步动作。停用权限仍可从列表打开详情并保持其状态和关联数量可见。

### 后端协作与结果

详情资格和直接关联角色数语义以[权限目录规则](../../domains/app.md#58-权限目录)为准；页面仅展示只读响应。

## 失败与并发响应

- 列表或详情请求失败时保留当前筛选或选中项，显示脱敏的业务错误和重试入口；不得把失败伪装成空列表或空详情，也不得使用假数据或旧请求的错误结果覆盖当前状态。
- 并发列表查询只接受最后一次请求的响应，较早响应不得覆盖较新的筛选、分页或结果。详情连续切换权限时只接受当前选中项对应的最新响应，较早详情响应不得覆盖当前详情。
- 权限目录没有页面内写操作，因此不自动重试或合并任何生命周期变更；若来源流程使目录状态变化，用户通过重新查询或重试取得最新结果。

## 验收场景

- 没有 `/app/permission/query` 时无法进入页面；没有 `/app/permission/get` 时列表不显示详情入口。
- 查询条件仅在明确提交后生效，每页固定 20 条，权限路径升序；旧的并发响应不能覆盖较新的列表或详情状态。
- 启用和停用权限均能保持可见，停用权限仍可打开只读详情。
- 详情只展示路径、领域、实体、动作、说明、状态和直接关联角色数。
- 页面不提供权限创建、同步、编辑或启停入口，不展示角色名单、来源对象、跳转入口或生命周期审计。
- 列表或详情失败显示错误和重试入口，不显示误导性的空结果、不泄露内部实现信息。
