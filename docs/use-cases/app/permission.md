# 权限目录页面用例

## 范围

- 路由：`/app/permission`，由 `app/permission` 登记。
- 权限目录的生成和有效权限计算以 [APP 最终权限计算](../../domains/app.md#4-最终权限计算) 为准。

## `APP-PERMISSION-01` 查询权限事实

1. 页面按领域、实体、动作和状态查询权限目录。
2. 选择权限后读取路径、说明、revision 与直接关联角色数。
3. 页面只读呈现目录，不提供绕过角色管理的权限写入。

## 验收

1. 查询与详情均来自可执行 APP 路由。
2. 失败时不使用本地目录伪装最新事实。
