# 角色管理页面用例

## 范围

- 路由：`/app/role`，由 `app/role` 登记。
- 角色类型、授权上限和管理保护以 [APP 最终权限计算](../../domains/app.md#4-最终权限计算) 为准。

## `APP-ROLE-01` 查询与维护角色

1. 页面按编码、名称和状态查询角色。
2. 新增或修改时加载启用的权限目录，并提交选择的权限 ID。
3. 保存和启停成功后重新读取角色详情及列表；不可维护角色只读展示。

## 验收

1. 页面使用服务端返回的 `manageable` 与 `availableActions` 呈现动作。
2. revision 冲突保留编辑内容并显示错误，不自动覆盖。
