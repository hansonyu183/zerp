# 系统参数管理用例

## 页面范围

- 路由：`/app/system-parameter`
- 领域规则：[系统参数模型](../../domains/app.md#38-系统参数)、[系统参数接口](../../domains/app.md#58-系统参数) 与 [管理接口通用规则](../../domains/app.md#6-管理接口通用规则)
- 线协议：[OpenAPI](../../../contracts/openapi/openapi.yaml) 与 [APP Schema](../../../contracts/openapi/schemas/app.yaml)
- 全站列表、筛选和并发请求规范：[前端工程约束](../../../frontend/AGENTS.md)

页面只展示和编辑领域规则允许管理的参数值；参数范围、敏感信息和只读边界以[系统参数模型](../../domains/app.md#38-系统参数)为准。

## `SPM-01` 查询系统参数

### 前端处理

1. 页面入口要求当前用户拥有 `/app/system-parameter/query`；没有该权限时由路由守卫进入“无权访问”。
2. 查询条件采用全站明确提交筛选：关键词、值类型和可编辑状态只在用户明确提交查询或应用筛选后生效；应用或重置筛选回到第 1 页。列表固定每页 20 条，按参数键升序。
3. 列表直接展示所有已注册非敏感参数的键、名称、说明、值类型、配置值、默认值和可编辑状态；不要求先打开详情才能读取值。
4. 只有同时拥有 `/app/system-parameter/get` 时列表才提供查看入口；只有同时拥有 `get` 和相应写权限时才显示编辑或恢复默认入口。`editable=false` 和没有充分注册约束的参数均不显示编辑或恢复默认入口。

### 后端协作与结果

查询资格和参数范围以[系统参数规则](../../domains/app.md#58-系统参数)为准；页面只展示查询响应。

## `SPM-02` 查看与编辑系统参数

### 前端处理

1. 查看详情要求 `/app/system-parameter/get`。每次进入编辑前必须调用 `POST /app/system-parameter/get` 读取最新完整详情、可编辑状态和 `revision`；列表行不能替代这次新鲜读取。没有 `save` 权限、参数不可编辑或没有充分注册约束时详情保持只读。
2. 编辑控件、候选值、必填提示和校验提示必须由同一份参数约束元数据派生；不得猜测约束或用通用自由文本绕过约束。默认值、当前配置值和拟保存值都必须满足基础类型及参数专属约束。前端校验只改善反馈，后端校验不可省略。
3. 可编辑详情展示配置值、默认值和约束。保存成功只表示配置值已经写入，不展示或推测部署实例加载状态。
4. 表单有未保存修改时关闭抽屉或离开详情必须确认是否放弃。保存提交编辑前 `get` 返回的 `revision`；提交期间禁止重复保存。成功后关闭或刷新详情，并重新查询列表，不在前端猜测写后状态。
5. `revision` 冲突时保留用户输入，提示数据已经变化并要求重新加载后再决定；不自动合并、重试或覆盖。详情连续切换参数时只接受当前选中参数的最新响应。

### 后端协作与结果

读取、保存与审计以[系统参数模型](../../domains/app.md#38-系统参数)和[系统参数规则](../../domains/app.md#58-系统参数)为准。页面只根据响应刷新配置值。

## `SPM-03` 恢复默认值

### 前端处理

1. 恢复默认值要求同时拥有 `/app/system-parameter/get` 和 `/app/system-parameter/reset`。操作前先读取最新详情；`editable=false` 和没有充分注册约束的参数不提供入口。
2. 二次确认明确展示参数名称和将恢复的默认值；确认后提交最新详情的 `revision`，提交期间禁止重复操作。
3. 成功后重新读取或刷新详情与列表，不提供或触发部署动作。
4. `revision` 冲突时保留当前详情和操作上下文，提示重新加载后再次确认；不自动重试。用户取消确认不发送请求。

### 后端协作与结果

恢复资格、默认值和事务语义以[系统参数规则](../../domains/app.md#58-系统参数)为准。页面成功后重新读取详情与列表。

## 失败与并发响应

- 列表、详情或筛选请求失败时保留当前筛选、分页和选中参数，显示脱敏业务错误与重试入口；不得伪装成空列表、空详情或使用假数据。
- 并发列表查询只接受最后一次请求响应；较早响应不得覆盖较新的筛选、分页或列表。详情与编辑前读取同样只接受当前选中参数的最新响应。
- `get` 后参数可能被注册流程、菜单服务或其他管理员改变；`save` 和 `reset` 必须以 `revision` 拒绝陈旧写入。冲突不自动合并、重试或把旧输入写回。
- 没有权限或参数不可编辑时，页面显示业务错误并保留当前上下文。

## 验收场景

- 没有 `query` 权限无法进入页面；没有 `get`、`save` 或 `reset` 时分别没有相应入口，伪造请求仍由后端拒绝。
- 筛选只在明确提交后生效，每页固定 20 条，参数键升序；列表直接显示所有已注册非敏感参数的配置值和默认值。
- 编辑前必经最新 `get`；控件和提示由约束元数据派生。未注册充分约束和不可编辑参数全程只读。
- 页面不能创建、删除或变更参数元数据，且不显示或登记敏感凭证类参数。
- 保存与恢复发生冲突或校验失败时不覆盖用户输入。
- 保存与恢复只反馈配置值写入结果，不跟踪部署实例采用状态。
- 关闭已修改表单必须确认放弃；恢复默认值必须二次确认；冲突与其他失败不覆盖输入或伪装成功。
