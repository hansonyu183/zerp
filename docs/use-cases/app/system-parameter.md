# 系统参数页面用例

## 范围

- 路由：`/app/system-parameter`，由 `app/system-parameter` 登记。
- 参数类型、约束和审计要求以 [APP 系统参数](../../domains/app.md#38-系统参数) 为准。

## `APP-PARAMETER-01` 查询与维护

1. 页面按参数键或名称查询参数。
2. 选择参数后读取当前值、默认值、可编辑性和 revision。
3. 保存或恢复默认成功后重新读取详情及列表；只读参数不呈现写操作。

## 验收

1. 页面不在本地重写参数约束，服务端错误保持可见。
2. 写入成功以读回值和新 revision 为准。
