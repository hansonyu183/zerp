# 用户管理页面用例

## 范围

- 路由：`/app/user`，由 `app/user` 登记。
- 用户、角色、授权上限和密码处理规则以 [APP 用户与权限](../../domains/app.md#4-最终权限计算) 为准。

## `APP-USER-01` 查询与查看

1. 页面按用户名、显示名称和状态显式查询固定分页列表。
2. 选择一行后读取用户详情及可分配角色；不可维护对象仍可只读查看。
3. 查询或详情读取失败时保留筛选，并显示服务端错误。

## `APP-USER-02` 新增与修改

1. 管理员输入用户名、显示名称、初始密码和角色后创建用户。
2. 修改显示名称或角色时提交详情携带的 revision。
3. 成功后重新读取详情与列表；冲突时不覆盖服务端事实。

## `APP-USER-03` 启停与重置密码

1. 页面仅呈现当前对象和权限允许的启停、重置密码动作。
2. 动作成功后重新读取详情，避免继续使用已过期 revision。
3. 重置产生的一次性临时密码只在本次成功响应后显示，关闭详情即清除。

## 验收

1. 页面不从角色名称或本地状态推断可维护性。
2. 创建、保存、启停和重置均以读回的服务端详情为最终结果。
