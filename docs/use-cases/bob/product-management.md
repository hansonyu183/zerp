# 产品管理页面用例

## 范围

- Registry 资源 `bob/product`，页面 `/bob/product`，用例键 `bob/product-management`。
- 业务字段、数量、配方、正式版本及独立启停规则以 [BOB](../../domains/bob.md#33-产品版本与独立启停) 为准；[Approval](../../domains/approval.md) 定义生命周期。
- 请求与响应引用可执行 [BOB 产品提交路由](../../../apps/api/src/bob/archive-contract.ts) 和[正式资料与启停路由](../../../apps/api/src/app/independent-contract.ts)。

## `BOB-PRODUCT-01` 正式资料与独立启停

有正式查询权限时进入页面加载一次；关键词查询、翻页和写后刷新沿用公共列表规则。详情显示本版本保存的全部字段、单位、配方和数量。独立启停使用对象 revision；动作成功刷新一次，冲突和未知结果分别反馈。

## `BOB-PRODUCT-02` 临时维护与提交

新建、克隆或变更打开当前页面的临时表单。
按权限加载产品类型、分类、计量单位及原料选项；已有采用值显示保存的名称。
变更预填正式资料；原料行按 [BOB 配方规则](../../domains/bob.md#21-业务字段)刷新选择，不能采用时显示待处理。
跨行为模板切换时确认删除不适用字段。

使用统一模型校验提交内容；单位试算只展示建议值，配方产量和用量仍明确输入基准数量。确定提交失败保留输入，未知结果先通过提交 ID 核实，不自动重放。取消、关闭、刷新和账号切换销毁临时输入。

## `BOB-PRODUCT-03` 提交件、审批与历史

提交记录与正式列表分开读取，版本历史展示完整不可变快照。审批动作同时受精确权限和服务器资格约束；失败显示稳定错误与引用 blocker。
旧配方、新产品版本及交易采用的精确快照可独立核对。

## 验收

1. 完整产品维护、提交、批准后，新业务候选读取已批准版本；已有交易数量和配方保持。
2. 候选批准不覆盖即时停用；最高正式版本先于关键词、类型和启停过滤，不回退旧版本匹配筛选。
3. 同条码并发提交只有一个成功；反批准不得恢复冲突条码。精确配方或正式交易引用阻止反批准。
4. 大额十进制数量、六位精度与转换建议不经过二进制浮点计算；临时表单关闭或账号切换不恢复。

## 动态版本档案交互（#410）

本资源从强类型 definition 经 Registry/Resource Host 装配统一版本档案页；页面生命周期、明细/详情/附件/历史区块及公开验收边界采用 [ADR-0060](../../adr/0060-dynamic-page-runtime.md)。上述业务用例在此真实入口验收，桌面和 390px 均覆盖，取消、未知写入、资源/Session 切换与迟到请求沿用全站规则。

新候选配方解析最新可用原料版本并保持基准用量；缺失或无权读取的原料标为待处理。只读历史继续显示原采用快照，单位试算不改写确认数量。

## 公共字段与录入操作验收

本页同时执行[公共字段与录入操作](../field-entry.md)的验收：普通字段采用同一基础呈现，保留原值、精确权限与取消行为；局部明细不创建提交表单。查询、保存或提交及明细增删使用与动作语义一致的图标和短中文，覆盖桌面、390px 与明暗主题。
