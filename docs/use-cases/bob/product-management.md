# 产品正式资料页面用例

## 范围

- 路由：`/bob/product`，Registry 资源 `bob/product`，用例 `bob/product-management`。
- 规则采用 [BOB](../../domains/bob.md)，维护边界采用 [DCL](../../domains/dcl.md)；HTTP 契约以可执行 Hono/Zod 路由为准。

## 正式查询与独立启停

1. 从“正式资料”菜单进入，按精确 query 权限直接查询当前资料，不再重复显示“正式资料”切换按钮；关键词显式提交，翻页保持已提交筛选。
2. 详情只读；启停按各自精确权限和 object revision 发起，失败显示服务端冲突或 blocker。
3. 对象详情按 versions 权限展示完整历史、状态、差异、只读快照及附件；跨对象 Entry 拒绝，不要求 DCL 审批权限，不显示维护或审批按钮。

## 验收

桌面和 390px 从实际菜单查询、查看对象历史及启停；待批仍显示旧正式版本，批准后采用新版，反批准回落不改变启停。历史明确标注状态，未批准记录不能被当作正式资料。权限不足不发请求，资源或 Session 切换忽略迟到结果。公共页面采用 [ADR-0060](../../adr/0060-dynamic-page-runtime.md)。

## 计量采用与数量验收（#442）

规则引用 [BOB 产品计量](../../domains/bob.md#21-业务字段) 与 [AUX 计量单位](../../domains/aux.md#35-计量单位)，协议来自 [产品可执行契约](../../../apps/api/src/dcl/archive-contract.ts)。

- 选择 kg/1、吨/1000 时显示单位固定系数，产品系数不可填写；试算 1 吨与 1000 kg 均建议基本数量 1000。
- 桶、袋等单位没有固定系数时，产品分别填写自己的系数；验证产品 A 桶/200、产品 B 桶/180。
- 产品修改保留已经采用的单位快照，单位 current 修改后打开历史产品仍显示原采用定义。
- 录入 1、1.2、1.23 可以提交，1.234 明确报错；基本数量及系数的高精度值保持原样。复制高精度历史配方时保留原值并提示显式重新确认，不自动修约。
