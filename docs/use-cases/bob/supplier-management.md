# 供应商管理页面用例

## 范围

- 路由：`/bob/supplier`，由 `bob/supplier` Registry 资源以 `bob/supplier-management` 登记。
- 当前资料、Submission、独立启停和权限规则以 [BOB](../../domains/bob.md#4-当前有效资料读取) 为准；请求及响应以可执行 BOB 路由为准。

## `BOB-SUPPLIER-01` 查询与独立启停

1. 页面仅在拥有正式资料 `query` 权限时加载供应商 current 列表；输入编码、名称或法定识别号后显式查询，翻页沿用已提交关键词。
2. 列表展示编码、名称和对象当前启停状态。启用和停用分别只在拥有相应精确权限时发起，并携带该对象 revision。
3. 成功后刷新当前列表；冲突、blocker 或未知结果以服务端结果呈现，不自行修改行状态或重放动作。

## `BOB-SUPPLIER-02` 提交资料版本

1. 新增、克隆或变更在本页临时表单中编辑；表单按需读取当前经营主体、员工和结算方式作为候选值。
2. 新增使用 `submit-new`，已有正式对象的变更先读取版本，再用 latest approved 来源提交 `submit-change`。取消、关闭、刷新或账号切换不持久化临时输入。
   未知提交经精确读取暂未找到后，用户显式重试采用当前表单内容，并保留原主体、提交 ID 和幂等键；读取未找到不证明原请求不会稍后提交，服务端幂等冲突仍须正常呈现，不能自动换键重放。
3. 提交成功后关闭表单并刷新 current 列表；失败保留输入和服务端错误，不能把候选或本地字段显示为正式资料。

## 验收

1. 启停不创建 Submission、不改变其 revision；提交、批准和反批准不覆盖对象启停状态。
2. 只有当前启用且存在 highest approved 版本的供应商可作为新业务引用；既有业务继续使用保存的精确 Approval Entry。
3. 缺少查询、引用读取、提交或启停所需的精确权限时，页面不发送对应请求。
