# 车辆用例

## 页面范围

- 路由：`/bob/vehicle`
- 车辆承运归属、散水能力和连续生效：[BOB 领域](../../domains/bob.md#24-车辆承运归属)
- 销售送货用车规则：[VOU 销售四单](../../domains/vou.md#32-销售四单)
- 线协议：[OpenAPI](../../../contracts/openapi/openapi.yaml) 与 [BOB Schema](../../../contracts/openapi/schemas/bob.yaml)

本用例只记录车辆页面的编排、状态和可观察结果。司机、运输任务、证照到期、维修、轨迹和调度不进入车辆主数据页面。

## 新建与保存

1. 新建车辆填写名称、车牌、车辆类型、承运归属，以及可选 VIN、发动机号、核定载重、散水承运能力和备注；编码由服务端生成。
2. 承运归属使用封闭二选一。选择“自有”时只选择存在最新已批准版本的经营主体；选择“外部承运”时只选择存在最新已批准版本的“其他单位”服务关系。切换类型先清除另一类型输入，页面不提供虚拟其他单位或临时承运方。
3. 散水承运能力使用独立开关并默认关闭；页面不根据车型、载重、名称或历史送货推断该值。
4. 创建或保存成功后打开服务端返回的详情并刷新列表。失败时保留输入和页面位置，显示业务消息及 `requestId`。
5. 关闭存在未保存输入的表单前确认放弃；确认不删除已经保存的首版草稿或候选版本。

## 列表与详情

1. 初次进入调用车辆 `query`；关键词、状态、启停、车辆类型和承运归属筛选由用户明确提交，分页与稳定排序采用全站规则。
2. 列表展示编码、名称、车牌、车辆类型、承运类型、承运方、散水能力、当前业务状态、启停状态和候选变更标记。
3. 查看、编辑和历史详情重新调用车辆 `get`。有开放版本时列表仍只显示一个车辆行，并以最新已批准版本作为当前送货资料；详情分别展示“正在变更”和“当前业务使用”。
4. 承运归属候选加载失败时显示明确错误并阻止空值继续操作；页面不得回退到自由文本承运方。

## 变更与启停

1. 编辑已批准车辆时创建开放版本；车型、承运归属、载重或散水能力待审期间，最新已批准车辆版本继续供新送货使用，审核成功后由最新已批准查询自然切换。
2. 需要立即阻止车辆继续承运时执行显式停用，不使用候选资料表达停运。停用成功后车辆不再进入新的送货选择，已有历史送货不受影响。
3. 经营主体或外部服务关系仍被当前车辆引用时禁用失败并提示车辆引用；用户进入车辆，通过正常编辑、提交和审核流程改归有效承运方后再重试。
4. 禁用承运方不得自动覆盖车辆开放草稿、切换承运类型、创建车辆已批准版本或修改历史送货快照。

## 异常与恢复

1. 车牌或 VIN 重复、承运归属失效、revision 冲突或字段校验失败时，保留用户输入并展示后端业务消息及 `requestId`。
2. revision 冲突允许用户复制尚未保存的输入后重新加载，不自动覆盖服务端版本。
3. 开放版本被撤回、驳回或删除时，最新已批准车辆继续供送货使用；列表和详情重新读取服务端结果。
4. 历史版本只读，按当时的车辆身份、承运归属和能力展示，不用当前经营主体、服务关系或车型名称重写历史。

## 验收场景

1. 自有车辆只归属一个经营主体，外部车辆只归属一条“其他单位”服务关系；页面不出现 `platformObjectId` 或虚拟其他单位方案。
2. 销售送货选择自有车辆时与订单经营主体一致；选择外部车辆时与送货承运服务关系一致。
3. 散水订单只能使用最新已批准版本明确具备散水能力的车辆，车型与核定载重不能替代该能力。
4. 车辆开放版本待审期间最新已批准版本继续可用；显式停用立即阻止新送货，但不改写历史送货。
5. 车辆页面没有司机、运输任务、证照到期、维修、轨迹或调度字段。
