# 复杂页面职责与集成

范围：[组件收敛 #418](https://github.com/hansonyu183/zerp/issues/418)，架构依据 [ADR-0060](../adr/0060-dynamic-page-runtime.md)。业务规则继续引用 [VOU](../domains/vou.md)、[BOB](../domains/bob.md)、[Approval](../domains/approval.md)、[WFL](../domains/wfl.md)；协议以 `apps/api/src/` 可执行路由为准。

## 页面编排与验收

- 从真实菜单进入所有 32 类人工单据，采用合法候选、填写必需明细、提交后通过类型化读取确认持久化，再克隆为新 Draft；会计期初独立完成录入、提交、回读及重新提交流程。四类系统生成单据没有人工新建入口，Submission 正文只读。
- 单据编辑区块只更新自身 Draft 或发出局部意图。页面负责保存、审批、请求身份和刷新；创建、克隆及载荷转换保持同一种单据的对应关系。关闭旧 Draft 后再新建，旧引用或附件响应不污染新实例。
- 居间计算分别编辑计算输入及脚本、查看结果；试运行成功才具备脚本保存资格，正式计算采用已保存版本。跨月克隆不继承旧计算结果。脚本未知保存和单据未知提交分别锁定并使用精确证据核实，关闭局部编辑器及普通查询不解锁。
- 五类 BOB 和 WFL 定义分别展示正式、开放候选、所选历史及审计。客户子单位、定价、产品配方及单位、WFL 图和编译试算保持可用；历史附件与引用保持冻结，重新采用遵循对应领域规则。
- 同时读取多个局部来源或附件时，先完成一项不能提前允许提交；取消不写不刷新，成功刷新一次，刷新失败不重放写入，revision 冲突不覆盖他人修改。资源或 Session 切换销毁旧实例。
- ACC 映射仍在保存时校验，RPT 保留 hasMore 与仅导出权限，WFL 节点未知动作仅凭同一 requestKey 的审计核实。
- 编辑、查看、克隆、审批及反向审批、核实、附件上传下载、历史审计、计算试运行使用一致语义图标和短中文。桌面与 390px、明暗主题下关键操作可达，表格在容器内滚动；仅图标控件具有可访问名称和键盘提示。

回归入口为真实 definition → Registry/Host → 用户操作 → 类型化 API 与可见结果，公共局部组件通过正式 props/事件验证。最终候选运行 `make check` 与 `make e2e`，逐项回读父规格 FC-01 至 FC-11；证据须记录实际 SHA、命令、退出码、范围和未执行项。浏览器仅连接本票独占可丢弃 Compose 服务，完成后显式回收。
