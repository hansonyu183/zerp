# 产品资料变更页面用例

## 范围

- 路由：`/dcl/product`，Registry 资源 `dcl/product`，用例 `dcl/product-management`。
- 采用 [DCL](../../domains/dcl.md)、[BOB 业务字段](../../domains/bob.md) 和 [Approval](../../domains/approval.md)；请求以可执行 Hono/Zod 路由为准。

## 提交及审批

1. 从“资料变更”菜单进入，按精确权限查询提交件并查看详情。
2. 新增、克隆在临时表单录入；修改读取明确正式版本基线。按需从现有辅助候选选择引用。
3. 提交成功关闭表单并刷新提交件；失败保留输入。未知结果锁定原主体、提交 ID 和幂等键，核实后结束，不能自动重试。
4. 审批按钮只呈现服务端允许动作，失败显示稳定错误和 blocker；不提供对象历史或正式对象删除入口。

## 验收

桌面和 390px 从实际菜单新增、克隆、修改和审批；取消、关闭、刷新和账号切换销毁临时输入。待批不影响 BOB 正式资料，审批不覆盖独立启停。缺少精确权限不发请求，迟到结果不串页。复用 [ADR-0060](../../adr/0060-dynamic-page-runtime.md) 公共页面。
