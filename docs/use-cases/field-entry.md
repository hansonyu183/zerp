# 公共字段与录入操作

本用例落实 [ADR-0060](../adr/0060-dynamic-page-runtime.md) 和 [#416](https://github.com/hansonyu183/zerp/issues/416)，覆盖直接维护、版本档案、单据、配置、报表与流程运行页面。业务规则及路由仍引用各页面原用例，本用例不定义 wire 或业务校验。

## 验收场景

- 从真实登记资源进入页面，填写文本、多行、密码、日期、金额、数量、枚举、多选及引用，通过既有类型化 API 提交并回显；金额数量的尾零和未完成输入不被公共控件改写，0、false 与空值保持区分。
- 筛选使用显式查询及既有范围校验，修改筛选不改变已提交快照。IME 选词不查询或保存；取消编辑不写入、不刷新。局部明细组合不生成嵌套提交表单。
- 用户不可再分配的已有角色、不可用 ID 和已采用历史快照完整回显；未改选不替换。并行引用、乱序响应及资源或 Session 切换保持原隔离。
- 客户子单位、产品单位与配方、所有人工单据区块及期初使用公共字段；明细添加与移除只改变 Draft。产品单位空值由业务模块提供。
- [ACC 映射](acc/mapping-management.md) 仍只在保存时校验；[RPT 参数](rpt/report-query.md) 保留原协议、真实候选分页与仅导出权限，不额外查询结果；[WFL 实例](wfl/process-instance.md) 保留节点动作及审计核实。
- 新增、查询、保存、提交、明细添加与移除显示统一语义图标及准确短中文，权限与事件不变。真实 Vuetify 装配验证字段与图标；桌面及 390px、明暗主题下文字可读、按钮可达，装饰图标对辅助技术隐藏。

## 普通引用统一读取（#427）

普通编辑与历史筛选共用 ReferencePicker，采用快照的字段由 SnapshotReference 适配。领域语义引用 [APP](../domains/app.md)、[AUX](../domains/aux.md)、[BOB](../domains/bob.md)、[VOU](../domains/vou.md) 与 [ACC](../domains/acc.md)。可执行入口分别为 `apps/api/src/app/independent-contract.ts`、`apps/api/src/app/aux-contract.ts`、`apps/api/src/acc/contract.ts` 和 `apps/api/src/vou/contract.ts`；逐消费者范围见[迁移矩阵](../testing/auxiliary-read-migration-matrix.md)。

1. 编辑器和筛选器打开后只请求当前候选页；搜索词变化回到第一页。超过 200 条时可通过搜索或后续页选择，不预载全集。多选跨页保留，清空只由用户触发。
2. 有效 Session 在没有来源实体管理权限时仍可读取候选；管理菜单与正式 POST 查询、查看及写入继续遵守各自授权。权限和角色候选使用服务端可分配结论；账簿候选仍受既有账簿范围控制。
3. 当前页与已选集合分离；历史停用资料可以用于筛选，编辑时不能作为新关联重新选入。已有身份、Approval Entry 和采用快照保持不变，不因候选刷新替换。完整快照无需 resolve；确需默认值或来源行事实时，所属业务适配器按已选精确身份读取。
4. 订单选择客户子账户、供应商或产品后，所属实体 resolve 提供必要默认值；首次订单缺少历史匹配时显示手工录入说明。订单产品协议只携带 ID；显式复制到新草稿时通过所属产品候选重新采用当前配置，保留原录入数量、价格和既有精确相对方引用，原单据不变；不可用产品明确要求重新选择。期初账簿、科目、资产和票据同样逐页加载，用户更换账簿时科目来源同步切换。
5. 加载失败显示中文说明与重试入口；非法查询条件有稳定错误。快速搜索、切源、关闭页面及账号变化后，旧请求结果不能回写。公共组件正式 props/事件、definition → Host 和浏览器 GET/POST 均覆盖这些边界。
6. VOU 来源行及 RPT 参数仍沿用本系列下一片的原专属读取；本片不改变其业务规则。
