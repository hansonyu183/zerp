# 公共列表与导航

依据 [ADR-0060](../adr/0060-dynamic-page-runtime.md) 和 [#417](https://github.com/hansonyu183/zerp/issues/417)。沿用各页面所引用的领域规则与可执行 API，不新增业务状态或 wire 字段。

- 从真实 Session 资源组经 AppLayout 导航和 ResourceHost 进入六类页面；菜单资格、分组、排序、路由与账号切换保持。
- 普通列表统一加载、空态、有限类型单元格和操作；正式版本、提交记录、单据、映射、流程保持真实身份。报表保留可见列、列宽、结果校验和本页展示键。
- total 列表显示真实总数及页数；hasMore 报表只显示前后翻页，不生成总数。编辑未提交输入后翻页与写后刷新仍读取已提交快照。
- 操作交集服务端可用动作和精确权限；取消零刷新，写成功一次刷新，普通查询不能解除未知写入锁。无查询权限保留已授权写入或导出，RPT 仅导出不查询结果。
- 已知资源与动作使用有限语义图标和中文名称；行操作只显示图标，中文名称用于无障碍标签、悬停和键盘聚焦提示。未知动态导航项未指定图标保留文本，非法图标在类型及运行时边界拒绝。菜单切换按钮保留无障碍名称，不显示提示浮层。
- 在桌面及 390px、明暗主题检查滚动容器、名称和按钮可达；复用真实 Host/API、查询快照、迟到响应、权限撤销及 Session 切换测试，并执行隔离环境 E2E。

实现与完整验证证据见 [#417 列表与导航验收](../testing/issue-417-list-navigation.md)。
