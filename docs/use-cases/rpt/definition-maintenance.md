# 报表定义维护

## 页面与依据

`rpt/definition` 由 [Registry](../../../frontend/src/target/navigation/registry.ts) 登记为 ConfigurationPage，业务规则见 [RPT](../../domains/rpt.md)、[ADR-0057](../../adr/0057-rpt-current-definition.md) 和 [ADR-0060](../../adr/0060-dynamic-page-runtime.md)。线协议与精确权限来自[可执行路由](../../../apps/api/src/rpt/contract.ts)。

## RPT-DEFINITION-01 查找与查看

有查询权限时加载维护列表。关键词、启用和有效性筛选显式提交，翻页沿用已提交条件；列表包含可修复的无效定义。只有保存权限时保留新增入口，不发无权查询。查看使用独立读取权限，只读呈现 SQL、参数、结果列、编码及有效性；编辑同时检查会话权限和服务端动作资格。

## RPT-DEFINITION-02 新建、修复与验证保存

新增时仅生成一次稳定身份，默认启用。编辑从读取结果保留身份和字符串 revision；编码及技术有效性只读。SQL 使用多行输入，参数与结果列使用公共子项编辑器，枚举子项提供值和中文名称，引用来源由闭合集合选择，默认值按参数类型录入。子项取消不改变父级输入，父级取消不写入。

验证保存调用现有 save；验证或 revision 冲突保留输入和旧定义，未知结果锁定提交且不重放。成功后显示新的 revision 和技术有效性，刷新列表及当前会话目录。列表或目录刷新失败独立说明已保存并提供重新读取，不能重发保存。切换资源或会话后迟到响应失效。

## RPT-DEFINITION-03 验收

覆盖只读、新建、编辑、停用、失效修复，所有参数与列类型及可选字段回填，非法 SQL 和零行元数据拒绝，维护与使用权限隔离；验证保存后任意报表名称在菜单、面包屑和正文一致，只有导出权限不触发查询。桌面及 390px 下检查子项编辑和列表操作，不以代表页替代其它批次资源。
