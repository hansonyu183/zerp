# 报表查询与导出

## 页面与依据

- `rpt/{code}` 由 [Registry](../../../frontend/src/target/navigation/registry.ts) 按报表编码登记，由 Resource Host 按 Session 精确权限装配。
- 业务规则见 [RPT](../../domains/rpt.md) 与 [ADR-0057](../../adr/0057-rpt-current-definition.md)。
- 输入、响应和权限见 [可执行 RPT 路由](../../../apps/api/src/rpt/contract.ts)。

## RPT-QUERY-01 查询

进入页面通过 GET `/rpt/directory/options` 读取授权目录中的本报表元数据，按参数类型装配输入。公共引用选择器自动调用该报表 GET reference-query 加载受控候选，不检查候选或 query/export 替代权限；搜索、分页、回显与重试沿用公共引用机制，业务约束见 RPT 领域规则。具备查询权限且必填参数已有值时初次查询，否则等待用户填写。显式查询提交完整参数快照，翻页复用该快照，编辑输入不立即执行。结果按返回列契约展示，金额保留字符串精度，不以当前资料名称覆盖返回的历史名称。

## RPT-QUERY-02 导出与部分权限

只有导出权限时仍可读取本报表参数、选择引用并导出，不发起结果查询。导出使用当前已校验输入，CSV 列名与值沿用返回契约。失败显示中文提示并保留当前输入。无定义维护功能，query/export 不赋予配置保存能力。

## 异常与验收

1. 多个参数 AND 条件、false、0、大金额和日期范围传到类型化 API；切换分页不采纳未提交输入。
2. 导出结果与同参数全部查询页一致；导出超限显示缩小范围提示。
3. 无权、非法参数、不可执行定义、引用失效及超时均显示明确反馈。
4. 当前定义修正后重新打开恢复执行；不选择历史版本。
5. 关闭、切换资源或账号销毁临时参数和结果，旧请求与导出不更新新页面或触发下载。

## 动态报表页

Registry 按编码生成唯一 report definition，公共页面拥有参数、每个引用源的独立请求序号、查询快照、分页、结果和导出。定义不携带 VM、模板或网络回调。不伪造总数或页码，沿用返回的 page 与 hasMore；参数和列依照受约束定义动态装配。

## 公共字段与录入操作验收

本页同时执行[公共字段与录入操作](../field-entry.md)的验收：普通字段采用同一基础呈现，保留原值、精确权限与取消行为；局部明细不创建提交表单。查询、保存或提交及明细增删使用与动作语义一致的图标和短中文，覆盖桌面、390px 与明暗主题。
