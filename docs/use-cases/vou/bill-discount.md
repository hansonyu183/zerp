# 票据贴现页面用例

权威业务规则见 [VOU 票据管理](../../domains/vou.md#313-票据管理)。#366 前当前 live 线协议见 [OpenAPI VOU Schema](../../../contracts/openapi/schemas/vou.yaml)；下文的本地 Draft、Submission 与 `submit-*` 描述由 Hono/Zod 路由生成的隔离 target，不能作为 live 接口调用。

## 1. 页面与查询

1. 页面入口为 `/vou/bill-discount`。进入页面后加载列表；关键词由用户按回车或点击“查询”后提交，分页固定每页 20 条。
2. 列表展示单号、业务日期、贴现方、状态和票面合计；详情从服务端重新读取，并按权限提供附件与审计入口。
3. 新增需要该实体创建权限以及贴现方和持有票据查询能力；条件不足时隐藏新增入口。

## 2. 制单编排

1. 新建时选择其他单位作为贴现方，录入业务日期、币种、利息承担方式、有无追索权和备注。
2. “选择持有票据”对话框按票据号码查询可选资产票据；确认后在表格中展示固定资料，只开放本次贴现年利率。
3. 页面按业务日期与到期日预览贴现天数和利息；资金区录入真实流入、流出，汇总区展示贴现票据、资金流入、资金流出和净到账。
4. 新单据只在浏览器 IndexedDB 本地 Draft 中保存；首次提交调用目标 Hono `submit-new`，从开放 Submission 克隆改正后调用 `submit-change`。成功后删除本地 Draft 并重读详情与列表，失败时保留本地正文和 Blob 附件并显示业务消息与 `requestId`。

## 3. 流转与验收

1. 本地 Draft 支持编辑、删除和附件维护；persisted Submission 不提供撤回或编辑，只提供符合资格的删除、驳回、批准、恢复审核、反批准及审计历史，并使用最新 revision；列表和详情只展示服务端返回的 `availableApprovalActions`。
2. 贴现方或承担方缺失、选择结果不可用、利率或资金行不合规时，页面保留已选票据，供用户修正或重新查询。
3. 批准时票据已被其他业务使用、期间冻结或反批准存在后续活动时，页面展示服务端阻断，不以本地预览替代权威结果。
