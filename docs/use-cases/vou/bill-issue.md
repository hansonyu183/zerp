# 票据开出页面用例

权威业务规则见 [VOU 票据管理](../../domains/vou.md#313-票据管理)，线协议见 [OpenAPI VOU Schema](../../../contracts/openapi/schemas/vou.yaml)。

## 1. 页面与查询

1. 页面入口为 `/vou/bill-issue`。进入页面后加载列表；关键词由用户按回车或点击“查询”后提交，分页固定每页 20 条。
2. 列表展示单号、业务日期、供应商、状态和票面合计；打开详情后按服务端响应展示票据、资金、附件及审计信息。
3. 新增、编辑和各流转动作按 `/vou/bill-issue/*` 精确权限显示。

## 2. 制单编排

1. 新建时选择供应商，录入业务日期、币种、备注和利息承担方式；选择第三方承担时显示其他单位搜索框，切回银行扣息后不得提交残留的承担方。
2. 票据区录入公司开出票据资料，页面以负债流入的开票模式呈现；资金区可录入真实保证金、手续费等资金收付。
3. 页面展示票据合计、资金流入、资金流出和票据净现金流预览，并提示利息预览不会自动生成资金行。
4. 保存成功后重新读取服务端详情和列表；失败时保持当前输入并显示业务消息与 `requestId`。

## 3. 流转与验收

1. 本地 Draft 支持编辑、删除和附件维护；persisted Submission 不提供撤回或编辑，只提供符合资格的删除、驳回、批准、恢复审核、反批准及审计历史，并携带最新 revision；列表和详情只展示服务端返回的 `availableApprovalActions`。
2. 供应商缺失、利息承担配置不完整、票据资料或资金行无效时，页面在对应字段附近提示并保留其他有效输入。
3. 服务端发现票据冲突、资金账户失效、期间冻结或后续活动阻断时，页面不改写本地状态为成功，用户可重新载入权威详情。
