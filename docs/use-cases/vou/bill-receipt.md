# 票据收入页面用例

权威业务规则见 [VOU 票据管理](../../domains/vou.md#313-票据管理)。#366 前当前 live 线协议见 [OpenAPI VOU Schema](../../../contracts/openapi/schemas/vou.yaml)；下文的本地 Draft、Submission 与 `submit-*` 描述由 Hono/Zod 路由生成的隔离 target，不能作为 live 接口调用。

## 1. 页面与查询

1. 页面入口为 `/vou/bill-receipt`。进入页面后加载列表；关键词由用户按回车或点击“查询”后提交，分页固定每页 20 条。
2. 列表展示单号、业务日期、客户、状态和票面合计；打开一行后从服务端读取完整详情，不以列表数据拼装编辑表单。
3. 新增、查看、编辑、生命周期、附件和审计入口分别按 `/vou/bill-receipt/*` 精确权限显示。

## 2. 制单编排

1. 新建时录入业务日期、币种和备注，通过 BOB reference query 选择客户及经办人。
2. 票据区可录入新收票据，也可从当前可用持有票据中选择找零票据；资金区按需选择资金账户并录入实际收付方向、金额类型、金额和备注。
3. 页面即时展示收入票据、找零票据、现金补款、现金找零和客户净结算额预览。前端检查只用于定位输入问题，最终规则以领域服务结果为准。
4. 新单据只在浏览器 IndexedDB 本地 Draft 中保存；首次提交调用目标 Hono `submit-new`，从开放 Submission 克隆改正后调用 `submit-change`。成功后删除本地 Draft 并重读详情与列表，失败时保留本地正文和 Blob 附件并展示业务消息与 `requestId`。

## 3. 流转与验收

1. 本地 Draft 支持编辑、删除和附件维护；persisted Submission 不提供撤回或编辑，只提供符合资格的删除、驳回、批准、恢复审核、反批准及审计历史，并携带页面持有的最新 revision；列表和详情只展示服务端返回的 `availableApprovalActions`。
2. 无客户或经办人、票据资料不完整、找零票据不可用、资金账户不可用或净结算不合规时，页面不得清空当前输入。
3. 并发修改、批准阻断或反批准存在后续活动时，页面显示服务端错误并允许用户重新载入详情，不伪造成功状态。
