# 单据目录列表

## 页面与依据

共享单据目录中销售、采购订单之外的既有类型由 [Registry](../../../frontend/src/target/navigation/registry.ts) 直接装配统一动态单据页；销售与采购沿用各自页面用例。业务依据为 [VOU](../../domains/vou.md#单据列表与详情)、[Approval](../../domains/approval.md) 和 [ADR-0052](../../adr/0052-session-dynamic-navigation-and-page-migration.md)。输入、摘要及完整详情以[可执行 VOU 路由](../../../apps/api/src/vou/contract.ts)为准，不另建单据类型枚举或协议。

## VOU-CATALOG-01 从真实菜单查询

按单据类型打开对应菜单，页面实例初始化自然月期间。提交期间、单号、提交日期、审批状态及本类型登记的专有条件，表格展示服务端摘要。名称筛选按采用时名称查询，资料改名不会改变旧单展示；无经办或金额事实显示“—”。翻页沿用完整已提交条件，清空名称不筛选，非法条件明确反馈。

## VOU-CATALOG-02 打开与审批

默认“打开”读取完整提交，显示表头、引用采用标识和姓名、明细、原币金额与数量、日期、备注及附件。系统生成类型明确提示不能人工新建；居间计算由公共单据页维护脚本、生成来源、计算并提交。已提交内容只读。审批复用公共 RowActions 和服务端资格，与账号精确授权相交；取消无写入，成功写入刷新一次，未知结果锁定并支持有权核实。

## VOU-CATALOG-03 权限与页面隔离

只具有审批权限的资源仍可进入菜单，但没有 query 权限不读取列表或引用；没有 get 权限不能打开详情。切换类型、退出或切换账号销毁旧实例，旧请求不能写回新页面。临时输入不持久化。

## 验收

1. 逐项打开共享目录内全部真实菜单，列表只请求准确类型，摘要与 get 内容一致；逐类能力及验证记录见[目录验收](../../testing/vou-catalog-issue-403-2026-09-08.md)。
2. 名称字面匹配、合法空值、经办事实、历史改名、服务端条件白名单、金额分位及日期契约通过 HTTP/数据库验收。
3. 系统生成类型无人工新建；审批资格与精确权限生效。专用编辑器的缺失不隐藏菜单。
4. 390px 下筛选、查询与行操作可达，表格自身滚动，不使整个页面超宽；只有审批权限时不读取列表或引用。

## VOU-CATALOG-04 采购履约、退货与生产库存录入

本组按 #412 验收销售退货、采购入库、采购退货、采购询价、生产配货、生产自制品及库存盘点。通过同一动态单据页新建临时表单，选择有权候选、填写日期、备注和明细，上传附件后提交并打开服务端保存的详情。逐类完成证据见[#412 录入验收](../../testing/vou-entry-issue-412-2026-09-09.md)。

来源行从可执行路由的 source-line/query 选择，显示来源单号、产品及可用数量。退货按候选返回的根订单归属，明细保留精确来源单及行；采购入库按来源采购订单归属。不同根订单不能混入同一表单；变更选择不自动清空已有明细，提交冲突由服务端最终判定。退货必须填写原因。

采购询价选择供应商与产品当前版本并录入价格。盘点选择仓库、产品和单位后录入数量，字符串数量不转换为浮点数。生产配货选择同一销售订单的配方行；生产自制品选择有固定配方的当前自制成品。两者按 [VOU 生产规则](../../domains/vou.md#34-生产配货与生产自制品)生成材料行，保留数量、损耗及调整原因，不提供任意增删配方行的入口。

取消销毁临时输入且不刷新。提交成功刷新一次；详情只读，克隆重新采用引用与附件。权限撤销、账号或资源切换后迟到请求不能更新表单，未知提交结果保持原身份锁定。桌面及 390px 均逐类验证候选、编辑、提交、持久化与详情回读。

本组库存协作按 [VOU 生产规则](../../domains/vou.md#34-生产配货与生产自制品)、[盘点规则](../../domains/vou.md#311-库存盘点)与 [ACC](../../domains/acc.md)验收：用户可读取账面预览，批准后从详情查看固定的账面、实盘与差异数量；库存冲突显示服务端 blocker，用户解除冲突后再操作。

## VOU-CATALOG-05 资金与费用录入

第二组覆盖销售收款、采购退款、其他收款、销售退款、采购付款、其他付款、员工借款、员工还款、员工借款核销、费用报销和其他收入。新建、取消、提交、打开及克隆继续使用同一单据页；依据 [VOU 收付款](../../domains/vou.md#36-往来收款与往来付款)、[员工借还款](../../domains/vou.md#37-员工借款还款与借款核销)、[费用报销](../../domains/vou.md#38-费用报销)和[其他收入](../../domains/vou.md#310-其他收入)。

有资金流的表单选择相对方、资金账户和经办人，填写日期、币种及金额；销售收款另选客户和实际经营主体，逐行选择客户子单位并填写分摊金额。费用报销和借款核销选择员工，编辑费用类别、说明、金额及备注，不展示资金账户或重复经办人。其他收入填写来源名称并可关联客户子单位或供应商。候选和所有跨引用关系均以服务端最终校验为准，失败保留表单并显示稳定业务提示，不自动补齐或改写金额。

其他收付款相对方完整协议值为 `customer-subunit`、`supplier`、`other-unit`、`employee`、`sales-partner`，页面分别显示客户子单位、供应商、其他单位、员工、销售合作方；其他收入的可选相对方只含前两种。可选其他类别 `COMMISSION`、`INTERMEDIARY` 显示佣金、居间费；选择项与详情复用单据范围的中文映射。金额始终以十进制字符串传递。分摊与费用行均有明确添加、删除入口，附件沿用公共区块。克隆保留业务事实但生成新的提交身份，不继承附件。

逐类验收包含桌面与 390px 的真实菜单、候选、金额和明细编辑、提交持久化、详情与克隆回读；另验收金额不一致、币种不匹配、权限不足和未知结果。入账及反批准冲突通过公开服务、Hono 和可丢弃 PostgreSQL 验证，具体规则链接权威领域文档。

## VOU-CATALOG-06 资产与票据录入

第三组覆盖资产购置、资产出售、资产清理、收票、付票、开票、票据贴现和票据到期。业务限制以 [VOU 固定资产](../../domains/vou.md#312-固定资产单据)、[票据管理](../../domains/vou.md#313-票据管理)及 [ACC](../../domains/acc.md)为准，入口和字段以可执行 VOU 路由为准。

资产购置选择供应商，逐行填写名称、规格、类别、原值、使用月数、残值率、部门、可选保管人、地点和备注；类别默认值可采用和覆盖。出售、清理从在用资产候选选择，分别填写出让金额或清理原因、残值收入与处置费用。选择资产显示编号和名称，不接受手填 ID。

收票、开票逐行填写票据种类、号码、介质、币种、票面金额、日期、出票人、承兑人、收款人、年利率及备注。付票、贴现和到期选择已有票据；收票可添加已有找零票据。头部显示本类型适用的相对方、经办人、计息方与追索等事实；现金明细独立选择资金账户、方向、金额类型、金额及备注。方向和用途由单据类型限定，不允许通过编辑协议原码绕过业务限制。类别、介质、计息方式、到期类型和资金方向等选择项复用单据范围的中文映射。

新建、附件、只读详情、克隆、未知结果及账号隔离继续由公共单据页持有。八类各验证双宽度的候选、录入、提交、持久化和详情回读；资产/票据状态在保存及审批时重新校验，后续处置存在时反批准明确拒绝，解除后可重试。此节完成证据记入同一[#412 验收记录](../../testing/vou-entry-issue-412-2026-09-09.md)。

收票录入只选择客户子单位，客户由所选子单位的归属推导；不另设客户选择或客户级余额。提交与克隆均保留子单位精确引用，入账使用 ACC 的 CUSTOMER_SUBUNIT 维度。

## VOU-CATALOG-07 定价、居间与服务录入

最后一组遵循 [VOU 定价](../../domains/vou.md#31-销售定价与采购询价)、[居间计算](../../domains/vou.md#24-居间计算单)和[服务规则](../../domains/vou.md#314-服务合同与履约验收)。销售定价复用商品价格明细，选择产品当前版本并填写正数单价，不选择供应商或仓库。提交、只读详情与克隆沿用公共单据页，保存后从详情核对采用的产品和价格。

服务合同选择其他单位或销售合作方及经办员工，录入合同条款、适用起止日期与合作能力；切换相对方类型保留原选择；不匹配时提示用户重新选择，切回原类型可继续采用。履约验收选择已批准的其他单位服务合同及经办员工，填写履约和验收日期、事实、结算方向及金额。合同不可用、期间或币种冲突由服务端拒绝并保留输入。结算方向 `PAYABLE`、`RECEIVABLE` 显示应付、应收；能力 `EXTERNAL_PART_TIME`、`CHANNEL_PARTNER` 显示外部兼职、渠道合作方，选择项与详情复用中文映射。

居间计算流程为选择月份、读取后端来源、采用已持久化脚本版本计算、查看明细和汇总、提交后回读冻结快照。脚本维护采用 revision 并发校验；具体业务公式后续通过脚本维护调整，不阻碍这条通用链路开发。未配置脚本、脚本执行失败、结果不合法、来源变化和月份冲突均明确反馈并保留可继续修改的输入，不伪造计算成功。克隆可以采用历史内容作为临时输入，但提交前须按领域规则重新取得并校验目标月份来源；读取历史单据不以当前脚本重算历史结果。

验收使用明确标为测试夹具的动态脚本，验证脚本保存与重读、revision 冲突、不同脚本版本产生不同结果、提交冻结和历史回读，以及来源变化和执行失败分支；夹具不作为默认业务公式发布。来源生成、全局脚本维护、页面计算和冻结快照共同组成完整录入链路。

计算脚本通过 `/vou/intermediary-calculation/script-get`、`script-save` 读取和保存；来源通过 `/vou/intermediary-calculation/source` 生成。页面分别检查这些精确权限。维护者填写名称和同步 `globalThis.calculate(input)`，先使用所选月份来源试运行，再保存；保存成功不自动改写已有计算稿，须点击重新计算。脚本未配置时无默认公式。第三方居间汇总同时显示客户子单位，其余分类显示相应 Employee 或 Sales Partner。历史详情只显示已保存快照。

验收包含：首次配置脚本并提交零来源月份、修改脚本后显式重新计算、并发脚本保存冲突、执行超时后可重试、错误结果被后端拒绝、来源变化后旧稿被拒绝、同月重复提交被拒绝，以及跨月退货按原稿冲回。计算动作持有公共单据页状态和写入锁，专用区块只呈现局部输入与结果。

## 公共字段与录入操作验收

本页同时执行[公共字段与录入操作](../field-entry.md)的验收：普通字段采用同一基础呈现，保留原值、精确权限与取消行为；局部明细不创建提交表单。查询、保存或提交及明细增删使用与动作语义一致的图标和短中文，覆盖桌面、390px 与明暗主题。
