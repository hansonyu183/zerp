# 居间计算单页面用例

## 范围

- 路由：`/vou/intermediary-calculation`，公共 Draft、查询、详情与生命周期编排见 [VOU 页面公共用例](README.md)。
- 业务不变量以 [VOU 领域文档](../../domains/vou.md#24-居间计算单) 为准；请求与响应只采用可执行 Hono 路由。

## 当前状态：本轮延期

本轮页面恢复不验收居间计算。它依赖的来源生成、脚本版本和结果一致性尚未由当前可执行契约与领域服务提供；通用 VOU 编辑器只会持久化客户端提交的快照，不能替代领域计算。

恢复必须作为独立的完整垂直切片完成，而不是以空来源、伪造 hash 或前端推断临时放行：

1. 明确销售伙伴等来源事实的归属，并实现按自然月生成可复现的销售、退货、收款 FIFO 与票据来源。
2. 增加来源生成、脚本读取/保存和权限的可执行 Hono 契约，以及脚本 revision/hash 的并发保护。
3. 在同一领域事务内核验来源、脚本、结果、票据分配与汇总；保存、复核和批准均拒绝过期计算，并补齐所需持久化关系。
4. 交付专用页面的重新计算、脚本试运行/保存和当前计算状态；随后补齐公共接口、集成及浏览器 E2E 验收。

在此之前，路由仅作为当前页面入口存在，不表示能够完成居间计算业务。
