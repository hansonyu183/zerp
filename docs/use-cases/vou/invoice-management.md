# 销售与采购发票

## 页面与领域边界

销售发票与采购发票使用单据公共运行时，遵循 [VOU](../../domains/vou.md) 的来源金额与冻结规则、[AUX](../../domains/aux.md) 的税务资料规则及 [BOB](../../domains/bob.md) 的正式关联边界。菜单资源为 `vou/sale-invoice` 和 `vou/purchase-invoice`。

## 编排

1. 选择客户或供应商的当前正式版本，选择经营主体、开票日期及币种。
2. 从 `GET /vou/{entity}/tax-options` 获取当前正式关联的启用税务项。一条自动带出，多条由用户选择，零条提示先维护并批准关联。
3. 从 `GET /vou/{entity}/invoice-sources` 读取同一对象、经营主体及币种的可开票来源，按来源填写本次金额。销售来源为已批准签收，采购来源为已批准入库。
4. 使用可执行 Hono 路由 `POST /vou/{entity}/submit-new` 提交，随后按单据公共运行时批准、拒绝、反拒绝、反批准或删除。
5. 提交事务重校对象正式版本、税务关联、启用状态、AUX revision 和可用来源金额，冻结完整税务内容。陈旧事实提示用户刷新，不静默替换或自动重试。批准沿用已提交税务快照，只重校来源金额。
6. 销售发票公共页面仅在拥有同名精确权限时显示未开票查询，使用 `POST /vou/sale-invoice/unbilled` 携带 CSRF 和月份。公共页面持有查询、结果和错误状态，按来源月份、客户、经营主体和币种展示并追溯签收来源；资源或 Session 失效后的迟到响应不得展示。

## 验收

共享税号不允许合并不同客户来源；部分及跨期开票分别扣减正确期间的来源余额。验收半分来源取整、分次退回全部数量后金额归零，以及恢复审核与另一待批发票占用冲突时保持驳回状态；对应规则见 [VOU](../../domains/vou.md)。只有未开票查询权限的用户可以查询，只有列表、提交或审批权限的用户不显示该入口；缺少 CSRF 的 POST 被拒绝。税务后续修改、停用和移除关联不改写提交后快照。桌面和 390px 均能完成候选选择、来源填写、错误恢复、详情查看及未开票查询。
