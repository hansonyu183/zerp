# 会计期初

## 页面与依据

- 页面 `vou/opening` 由 [Registry](../../../frontend/src/target/navigation/registry.ts) 登记，经 Session 菜单打开。
- 生命周期与归属见 [VOU](../../domains/vou.md)、[Approval](../../domains/approval.md)、[ADR-0059](../../adr/0059-vou-accounting-opening.md)；账务规则见 [ACC 账簿期初](../../domains/acc.md#6-账簿期初)。
- 输入、分页摘要、详情、动作、审计与精确权限以[可执行期初路由](../../../apps/api/src/vou/opening-contract.ts)为准；账簿与科目选项使用[可执行 ACC 路由](../../../apps/api/src/acc/contract.ts)，业务引用使用[可执行 VOU 引用路由](../../../apps/api/src/vou/contract.ts)。

## VOU-OPENING-01 查询与只读详情

由统一动态单据页持有列表、详情、审批及提交状态，默认当前自然月，支持账簿起始期间、单号和审批状态。查询与翻页沿用已提交筛选，后发请求优先。列表只取摘要；打开后显示原始期初明细、资产、票据、空桶快照与审批信息。金额为逐行原币事实，不制造跨币种合计。无 query/get 权限不发送对应请求；每次读取由服务端校验账簿查询范围。

## VOU-OPENING-02 临时编辑与提交

分类录入区块只维护所属值与候选交互；新建时从有权查询的账簿与末级科目选择；每条明细填写币种、借贷、金额及科目要求的维度、库存数量。资产、票据允许新增登记或关联已有对象，空桶选择客户子单位。每类选项先检查其精确读取权限，不扩大授权。未填写任何登记也可以显式提交零期初。

确定失败保留全部输入和本次提交身份；成功关闭表单并刷新列表一次，刷新失败单独提示提交已经成功。未知结果保留并锁定输入，通过 get 核实原 submissionId；不自动重试。关闭、刷新、切换账号或离开资源销毁输入。已有提交不可原地编辑；复制只预填新临时表单，重新提交前需显式删除原开放提交，批准提交需先在原详情反批准。

## VOU-OPENING-03 审批和删除

详情动作使用服务端 availability 与精确权限，账簿操作范围也必须允许。批准与撤销动作遵循公共审批规则；所需原因由用户填写，取消不写入。执行 blocker 显示原因并保持原状态；陈旧 revision 要求刷新。未知审批或删除结果锁定原提交，经详情或精确审计核实，不重放。删除只释放开放提交，保留历史审计；不自动修改其他业务引用。

## 验收

1. 实际页面提交零期初，由另一操作人批准；关闭或刷新不恢复临时输入。
2. 非零输入借贷不平衡时失败并保留金额；补齐平衡明细后提交成功。390px 下表单与按钮可达，表格在容器内滚动。
3. 批准后允许普通 VOU 新记账；已有后续事实或锁定期间时反批准返回 blocker，无后续事实时同事务撤销期初效果。
4. 下游 ACC 校验或持久化失败时 Approval、审计与全部账务事实回滚；重复同意图提交不创建第二份期初，改变输入或操作者复用幂等键被拒绝。
5. 历史迁移保留 bookId、Entry、快照、引用、审计与精确授权；ACC 不再提供期初审批路径。无 query 账号保留有权菜单，但不发送列表或引用请求。

## 公共字段与录入操作验收

本页同时执行[公共字段与录入操作](../field-entry.md)的验收：普通字段采用同一基础呈现，保留原值、精确权限与取消行为；局部明细不创建提交表单。查询、保存或提交及明细增删使用与动作语义一致的图标和短中文，覆盖桌面、390px 与明暗主题。
