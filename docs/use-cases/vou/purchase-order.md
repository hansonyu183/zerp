# 采购订单

## 页面与依据

- `vou/purchase-order` 由 [Registry](../../../frontend/src/target/navigation/registry.ts) 登记，经 Session 菜单和 Resource Host 打开。
- 业务规则以 [VOU](../../domains/vou.md)、[Approval](../../domains/approval.md)、[ADR-0052](../../adr/0052-session-dynamic-navigation-and-page-migration.md) 为准。
- 查询、详情和审批协议见[可执行 VOU 路由](../../../apps/api/src/vou/contract.ts)；引用选项直接消费 BOB 的受控 current 读取，协议见[可执行独立资源路由](../../../apps/api/src/app/independent-contract.ts)。

## VOU-ORDER-01 从菜单检索

每次打开页面初始化当前自然月期间；本页显示供应商筛选。期间与提交日期使用同一个日期范围输入。查询按钮或非 IME 回车提交输入快照，翻页复用该快照；输入修改不改变已提交查询。状态、相对方与单号组合过滤后显示服务端 total。没有 query 权限时保留资源入口并说明权限，不发送列表或引用请求。引用选项没有自身读取权限时不请求，也不扩大授权。

## VOU-ORDER-02 打开与审批

默认行操作“打开”经 get 获取完整提交，显示订单引用、产品行、数量与单位审计快照、价格、配方、备注和附件，以及当前审批信息。已有内容只读；需要改正时复制到新的临时表单。审批操作来自详情可用动作和精确授权交集；需要原因时由用户输入，取消无写入、无刷新。成功写入刷新列表一次，刷新失败单独提示写入已成功。

## VOU-ORDER-03 异步隔离与未知结果

后发查询优先；关闭详情、切换单据类型或账号后，旧请求不能回写新页面。未知审批结果锁定该单据，普通查询不解除锁定、不重放操作；有核实权限时显式读取精确提交和原子审批审计确认结果。未能确认则继续保持锁定。

## VOU-ORDER-04 人工录入与克隆

Resource Host 直接装配统一单据页，运行时拥有 Draft、提交身份、互斥及写后刷新。新建从有权候选选择相对方、人员和仓库；销售同时选择经营主体、采用客户默认备注和显示内部提醒。主动重选采用当前版本，克隆未修改的相对方保留历史采用语义；产品和原料重新采用当前有效版本。客户默认值、收款方式、基础价格及销售加价遵循 [VOU](../../domains/vou.md)，未决价格组合不在页面新增算法。

商品行选择产品、该版本的单位，填写录入数量、确认基准数量及价格。销售按产品类型采用并编辑局部配方，定制品从当前客户最近有效订单采用；来源缺失时明确提示手工维护。通用字段、明细和局部配方区块不接管页面提交。附件使用统一附件区块暂存并随提交采用，克隆附件需重新上传，不继承旧暂存身份。

提交成功关闭 Draft 并刷新已提交查询一次；确定失败保留输入，未知结果保留原提交身份并锁定该页面的提交，普通查询或关闭 Draft 不解锁；有 get 权限可显式核实精确 submissionId。取消无写入、无刷新；资源和 Session 切换隔离迟到响应。submit-change 不用于编辑已保存正文。

## 验收

1. 真实采购订单数据的摘要、服务端多条件过滤、total/分页与完整详情一致；缺失经办人如实显示“—”。
2. 本页订单完成审批动作，提交人不可审批自己的提交；已提交内容保持不可变。
3. 基础期间与扩展提交日期共用 renderer；390px 下筛选、查询、打开与审批按钮可达，表格在容器内横向滚动。
4. 无 query 资源不发送任何列表或引用请求，输入快照、乱序、账号/类型切换隔离及未知写入保持。

5. 从真实菜单新建并选择合法候选、商品、单位及必需配方，上传附件、提交并回读；克隆后重新采用引用，原 Submission 不变。缺少候选权限不发送请求；390px 下可完成录入。
