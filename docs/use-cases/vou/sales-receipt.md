# 销售收款页面用例

本页面遵循 [VOU 领域规则](../../domains/vou.md#36-往来收款与往来付款) 和 [OpenAPI VOU Schema](../../../contracts/openapi/schemas/vou.yaml)。

## 1. 页面与查询

1. 页面入口为 `/vou/sales-receipt`。列表展示单号、业务日期、客户、实际经营主体、金额与状态；打开单据后展示返回的详情。
2. 新增、查看、编辑、生命周期、附件与审计入口按 `/vou/sales-receipt/*` 精确权限显示。

## 2. 制单编排

1. 用户录入业务日期、币种、备注、来款总额，选择客户、实际经营主体、资金账户与经办人。
2. 分摊编辑器按所选 Customer 提供当前启用客户子单位，并按 [DCL 的隐式选择规则](../../domains/dcl.md#361-客户与客户子单位申报) 处理预填或要求用户选择；每个选择及其金额组成分摊行。
3. 页面将表单引用和分摊提交给服务端；前端只提供即时输入提示，规则以领域服务为准。
4. 新单据只在浏览器 IndexedDB 本地 Draft 中保存；首次提交调用目标 Hono `submit-new`，从开放 Submission 克隆改正后调用 `submit-change`。提交成功后删除本地 Draft 并重新读取详情和列表；失败时保留本地正文与附件，显示稳定业务错误和 `requestId`。

## 3. 流转与验收

1. 提交和批准复用 VOU 统一生命周期；页面只使用服务端返回的 `availableApprovalActions`。
2. 保存或流转失败时，页面保留用户输入并显示服务端的稳定错误与 `requestId`。
3. 并发修改、引用失效和批准阻断均按统一错误呈现处理；历史详情始终使用服务端返回的快照。
