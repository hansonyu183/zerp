# 履约验收用例

## 范围

- 路由：`/vou/service-acceptance`。
- 可验收合同、履约事实、结算方向和 ACC 结果以 [VOU 领域](../../domains/vou.md#314-服务合同与履约验收) 为准；线协议以 [OpenAPI](../../../contracts/openapi/openapi.yaml) 及 [VOU Schema](../../../contracts/openapi/schemas/vou.yaml) 为准。

## 列表与编辑

1. 页面初次进入及用户明确提交筛选后查询，固定每页 20 条；列表按稳定业务顺序展示单号、合同、相对方、日期、金额和状态。
2. 新建只查询当前已批准的服务关系合同。选择合同后展示只读合同及相对方快照，用户录入履约日期、验收日期、应付或应收方向、金额、履约事实和验收事实。
3. 保存、提交、驳回和批准均使用最新 revision；失败保留输入并显示业务错误与 `requestId`，成功后重新读取服务端详情。列表和详情只展示服务端返回的 `availableApprovalActions`。

## 验收场景

1. 销售合作合同、未批准合同、已反批准合同和错误相对方类型不能流转验收。
2. 审核时重新锁定合同状态和类型；保存后合同被反批准的草稿验收不能继续通过审核。
3. 验收批准形成带服务关系维度的其他应付或其他应收事实；RPT 的费用归集、对账和物流跟踪不回写 BOB 关系明细。
