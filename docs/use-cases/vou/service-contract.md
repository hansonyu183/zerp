# 服务合同用例

## 范围

- 路由：`/vou/service-contract`。
- 合同相对方、结算快照、销售合作能力和生命周期规则以 [VOU 领域](../../domains/vou.md#314-服务合同与履约验收) 为准；线协议以 [OpenAPI](../../../contracts/openapi/openapi.yaml) 及 [VOU Schema](../../../contracts/openapi/schemas/vou.yaml) 为准。

## 列表与编辑

1. 页面初次进入及用户明确提交筛选后查询，固定每页 20 条；关键词、状态和相对方筛选不在输入时自动请求。
2. 新建时互斥选择有效的服务关系或销售合作关系，并选择当前有效经办雇佣关系。页面只提交强类型引用，主体、经营主体、关系名称和经办人名称均由后端保存快照。
3. 服务关系合同优先带入其当前有效默认结算方式，允许改选；没有默认值时要求用户选择。销售合作合同填写覆盖能力和适用日期，不显示履约验收入口。
4. 保存、提交、审核、驳回和撤回失败时保留表单及筛选，显示业务错误与 `requestId`；成功后使用服务端响应重新读取详情和列表。

## 验收场景

1. 裸 Party、客户关系、供应关系和已失效关系不能作为合同相对方。
2. 合同批准前重新校验相对方、经办雇佣关系、结算快照及销售合作能力；revision 冲突不产生部分更新。
3. 服务关系合同可进入履约验收；销售合作合同只供居间收益自动匹配，页面不允许逐条手工指定收益合同。
