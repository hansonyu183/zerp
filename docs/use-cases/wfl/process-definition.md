# 流程定义管理

## 页面与依据

- `wfl/process-definition` 由 [Registry](../../../frontend/src/target/navigation/registry.ts) 注册，Resource Host 按 Session 精确权限装配。
- 业务规则见 [WFL](../../domains/wfl.md)、[Approval](../../domains/approval.md)、[ADR-0058](../../adr/0058-wfl-owns-versioned-definitions.md)。
- 输入、响应和权限见 [可执行 WFL 路由](../../../apps/api/src/wfl/contract.ts)。

## WFL-DEFINITION-01 当前与提交读取

默认显示当前定义；显式切换提交记录后读取提交接口。有资源动作即可进入，无当前查询权限时不发送查询。当前详情、精确提交、版本历史和审计分别检查读取权限，当前读取不要求提交权限。关键词显式提交，翻页复用完整已提交筛选；写成功刷新一次，刷新失败保持写成功反馈。

## WFL-DEFINITION-02 临时编辑与审批

新建或克隆预填页面内临时脚本，变更以已批准提交为基线。使用者选择已存在试算单据并执行编译/试算，输入变化使此前成功试算失效。提交后只读展示，审批动作使用服务端动作集合与精确权限；原因由使用者输入。确定失败保留输入；未知写入阻止重放，只按精确提交或此次动作结果核实。关闭、刷新或账号切换销毁输入，旧异步结果不得回写。

## WFL-DEFINITION-03 启停、版本与实例

定义开关即时影响未来匹配，版本审批与启停独立。历史版本只读并展示实际审批资格。实例从 WFL 实例资源读取，显示启动时定义与实际节点；下级动作依据后端动作和目标集合执行，继续经过真实 VOU 写入口。定义变更、停用、根单据重新批准后，旧实例仍采用原版本。

## 验收

1. 定义编辑、真实试算、提交、审批、启用、根单据批准、实例创建、新版本批准与旧实例继续创建下级闭环。
2. 当前只读、提交只读、审批与执行的部分权限互不扩大。
3. 审批职责分离、陈旧 revision、唯一开放提交与精确实例引用 blocker。
4. 相同提交与 create-child 意图不重复写入；未知结果不因普通刷新解除。
5. 迁移保持身份、历史 Entry、运行事实与精确授权，失败整笔回滚。
