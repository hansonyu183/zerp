# 流程实例

## 页面与依据

- `wfl/process-instance` 通过 [Registry](../../../frontend/src/target/navigation/registry.ts) 和 Resource Host 装配。
- 业务规则见 [WFL](../../domains/wfl.md)，输入与精确权限见 [WFL 可执行路由](../../../apps/api/src/wfl/contract.ts)。

## WFL-INSTANCE-01 查询与节点动作

按名称、代码、根单据关键词显式查询，翻页复用已提交输入。实例详情显示启动时定义名称、精确版本和实际节点。每次查询或打开都会失效更早请求；切换账号销毁结果。只有定义维护权限不获得实例查询或执行权限。

打开单据先执行 WFL 打开动作记录，再按 VOU 精确读取权限展示单据；记录成功而正文读取失败分别反馈。创建下级只从服务端返回目标选择，其他节点动作只从服务端动作集合呈现。确定失败保留原因输入，未知操作按对应请求的运行审计核实，不重放。

## 验收

旧实例在定义修改、批准或停用后保留原版本和动作语义。create-child 重复意图不创建第二份单据；重批和反批继续遵守 [WFL](../../domains/wfl.md) 的 blocker 与幂等规则。浏览器闭环与[流程定义管理](process-definition.md)共同验证。

## 动态流程运行页

Registry 只登记流程运行 definition，公共页面持有实例、节点动作、原因、结果及有权审计；节点区块只显示所辖节点和发出有限动作意图。服务端动作集合与精确 action 路径取交集；打开单据还需要对应 VOU get 权限。未知写入（含无法解析响应和服务器内部错误）保留原 requestKey，核实只接受该请求的审计；普通查询和切换实例不解除锁。写成功后列表刷新失败明确显示已成功，不重放动作。
